# Training: primary fire and optional debris

Only explicit scout Training gains this coaching. Ordinary Swarm remains immediate-horde combat.
The opening offers fitted primary fire with the live binding, or a nearby rock with the live tether
binding. Held-rock contact is valid; releasing the line is optional. Touch/missing bindings never
invent buttons. Hints-off retains the plain-language weapon choices without step-by-step coaching.

Latch, deliberate cut and genuine player massline-impact receipts drive optional feedback. Entity
identity/generation, hostile cohort, current tick and owner-record checks prevent stale or fabricated
success. Coaching never completes an objective, awards damage, releases a pack or changes inputs.

`test/swarm-opening-options.test.mjs` and `test/swarm-opening-throw-coaching.test.mjs` exercise the
current announcer, binding resolver, cut producer and impact observer with explicit dependency ports.
Browser/native encounter, rendered legibility and audible timing still require runtime validation.

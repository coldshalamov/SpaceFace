# Agentic development architecture

This directory is the durable design layer behind `design/program/CENTRAL_BRAIN.md`. It exists to preserve the full architecture and rationale while the root `CANONICAL_BUILD_MAP.md` stays a compact implementation router.

Read in this order for broad autonomous development:

1. `AGENTIC_GAME_DEVELOPMENT_OS.md` — authority, manager/worker/scout/integrator roles, allocation, anti-recursion, Jules and INFERENCE boundaries.
2. `QUALITY_SCORECARD.md` — evidence freshness, quality floors, severity/exposure/leverage, L0–L3 visual maturity.
3. `OBSERVABILITY_REPLAY_AND_PLAYTEST_ARCHITECTURE.md` — exact `sessionObserver`/runtimeWitness/lab/Combat Lab integration, replay artifacts, autonomous play and calibrated detectors.
4. `IMPLEMENTATION_ROADMAP.md` — staged path from the current advisory manager to live observability and autonomous playtesting.

Specialized durable plans:

- `PLAN_CONVERGENCE_PROTOCOL.md` — reconcile the many existing plan families without creating another backlog.
- `CONTENT_FACTORY_AND_COMPLETENESS.md` — role/doctrine/counterplay-driven content breadth rather than raw row count.
- `INFERENCE_PROTOCOL.md` — bounded divergence, selection, production and termination.
- `VISUAL_DIRECTION_AND_VFX_SYSTEM.md` — luminous arcade aerospace, screen-space value and causal structural VFX.
- `PERFORMANCE_GOVERNANCE.md` — same-picture, evidence-first performance work.

Machine/operator surfaces live in `tools/agentic/` and `design/program/AGENTIC_QUALITY_WORKSTREAMS.json`. The PQ queue remains the only admitted machine index; these documents never constitute a second queue or acceptance system.

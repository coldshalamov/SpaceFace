## Notes

ATMO CREDIT is structurally the inverse of ATMO DEBT. The same ledger entry that records the Pit's fourteen-year debt records Helios Prime's fourteen-year credit. The two numbers are the same transaction viewed from opposite ends. The commodity board showing both is the player's first quantitative read on the system — if they watch the Pit's column long enough, the number corresponds exactly to the maintenance the Pit would have received if the recycler catalyst grid had not been removed.

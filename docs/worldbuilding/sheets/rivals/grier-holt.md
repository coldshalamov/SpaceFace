## The code

Grier's code is the most interesting thing about her, because the code is *almost* moral. She doesn't kill civilians (she checks). She doesn't double-bill (she reads the contract). She doesn't renegotiate (the fee is the fee). The code is clean *by its own terms*. The code does not include "verify the client's authorization chain" or "confirm the target is actually a pirate." The code assumes the license is clean. The license is not clean. Grier is the B2 beat (crime-without-punishment) made into a recurring professional whose professionalism is the disease.

## Coercion hook

Grier and the player cross on contracts — sometimes competing, sometimes on opposite sides of a contested tag. Grier will not shoot first if the contract doesn't specify. Grier will shoot last if it does. The player who reads the same contracts Grier reads (the authorization lines) can predict her. The player who doesn't is surprised when the Hornet drops out of the lane.

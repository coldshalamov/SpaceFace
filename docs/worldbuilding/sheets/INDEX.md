## How to use this index

- **Finding an entity:** look it up in the table above → follow the `sheet` path for structured fields → follow the `canon prose home` path for the voice.
- **Updating an entity:** edit the prose canon (the voice), then update the sheet fields to match. Never carry the same sentence in both places.
- **Adding a Dosto theme:** cite `DOSTOYEVSKY-LAYER.md` by theme id (`theme: guilt_as_physiology`). Do not name Russian authors in body prose.
- **Cross-tree links:** world sheets link to `design/world-identity/sectors/*.md` (render/palette/GLB) and back. The two trees do not overlap in owned fields.
- **Continuity check:** every chapter footer names its entities by sheet id; this index's reverse-lookup (`appears_in_chapters` on each sheet) confirms coverage.

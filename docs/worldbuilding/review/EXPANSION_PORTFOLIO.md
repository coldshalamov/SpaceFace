# SpaceFace — Expansion Portfolio (+30% integrated)

**Companion to:** [`LITERARY-DEEPENING-GOAL-RESULT.md`](./LITERARY-DEEPENING-GOAL-RESULT.md)  
**Count after Pass-5 cut:** **27 units** (target ~30; cut 3 weakest)  
**Rule:** integrated density, not appendix bulk. Each unit must pass ≥2 multi-edge tests.

### Multi-edge tests
1. **Recontextualization** — changes meaning of an earlier beat when found  
2. **Convergence** — shares object/code/weight/name with ≥2 other units  
3. **Choice residue** — affects ending ease, post-ending texture, or filing  
4. **Embodiment** — cargo, graffiti, encounter, landmark, board contract, HUD  
5. **Register fit** — Pit inventory/log voice, not theme essay

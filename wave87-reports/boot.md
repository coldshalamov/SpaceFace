### F1 — keepGpu restore pays a whole synchronous `reconcileMeshes` inside a shell-visible `prepareFrame`
- **Evidence:** `src/render/renderer.js:2062` — `if (owner._meshReconcileDirty) owner.reconcileMeshes({ keepResidentSet: true });` inside `serviceRenderMeshResidency`, which `prepareFrame` invokes every tick at `renderer.js:23332` — including while `state.mode === 'loading'` owns the DOM shell. `reconcileMeshes` sync-exhausts `_reconcileMeshesSteps` (`20688–20700`: `const it = render._reconcileMeshesSteps.call(this, options); for (;;) { const step = it.next(); if (step.done) return step.value; }`). The stepped, paced pump exists in the *same function* at `2367–2421` (4 ms slice clock + `pacedFrameSpend()` ledger, epoch-gated) but is unreachable here: the keepGpu branch returns `'session-recook-keep-gpu'` at `2064` before control reaches it. `_meshReconcileDirty` is armed on exactly this path at `17155` (`save:loaded` under `_sessionRecookKeepGpu`) and `17018`.
- **Mechanism:** on a same-sector Continue/restore, one prepareFrame tick pays the entire reconcile — chunked `collectMeshPresentationEntities` census + per-row residency grading + keepResidentSet release walk + build-queue mint — O(entities)+O(meshes) inside a single JS task under the loading shell. The loading bar's DOM updates starve for that span: a visible mid-restore freeze of the very class this lane hunts.
- **Fix sketch:** in the keepGpu branch, mint `owner._reconcileIter = owner._reconcileMeshesSteps({ keepResidentSet: true })` with `_reconcileEpoch` and drive it under the existing 4 ms / paced-ledger clock (extract the driver at `2388–2420` or inline a twin), then `_drainPendingMeshBuilds` as now. Keep the ordering constraint: run the feed-gated reattach sweep to completion *before* the first reconcile leg, or `keepResidentSet` releases dead-id meshes the sweep hasn't moved yet. The staged twin is already written for suspension (`refreshOnNewerSweepBeat`, re-dirty-on-suspend at pass start).
- **Effort:** M. **Impact:** H. **Risk:** M — ordering vs. reattach; suspension semantics already designed-in.

## Ranked findings

### 1. Depth-stage leg failures bypass both the arm's fault-park and laneWarn — persistent leg failure warns + re-arms every ~48 ms for the whole epoch

- **Evidence:** inside `_armDepthStage`, the async promote leg's promise `.catch` at renderer.js:29442-29444 sets `legDriveFailed = true` and `console.warn('[render] shadow-promote depth stage fallback failed', error)`; the synchronous leg-setup `try/catch` at 29517-29520 warns `'[render] shadow-promote depth stage failed'`. Neither path rethrows into the arm's outer `try` at 29232 — so the outer catch at 29635-29647 (the `_depthStageArmFaults` counter + `noteLaneFault('depthStageArm')` + ≥3 park, added W109/W110) never increments on leg faults. Meanwhile the `finally` at 29650-29662 re-arms (`this._armDepthStage()`, `idleBoundMs: 48`) whenever `pending.size > 0` — and roots requeued by the failed leg keep `pending` non-empty. Third site in the same family: `_stageShadowDepthOnSettingEnable`'s tail catch at 29829 (`'[render] shadow-enable depth stage failed'`) is a raw `console.warn` outside laneWarn with no stamp.
- **Mechanism (hunt a — worst-case volume):** a persistently-faulting staging leg (e.g. a poisoned signature accessor under one subtree class) produces ~20 warns/s unbounded for the whole epoch — the arm's own cadence — while also paying the arm ceremony (collect + sort + slice + mark-check passes) every ~48 ms. Two contract holes in one: warn volume unbudgeted, and the "≥3 faults parks" protection the sibling lanes all got never fires for the dominant fault path of this lane. Roots stay withheld (shadows dark) *without* the parked verdict that would stop the churn.
- **Fix sketch:** route all three catches through `laneWarn(this, 'depthStageArm', ...)`; count `legDriveFailed === true` (and the 29519 catch) into `_depthStageArmFaults` in the arm `finally` so a persistent leg reaches the ≥3 park the outer catch already implements. Optionally stamp `noteLaneFault(state, 'depthStageArm', faults >= 3)` from the leg settle — the lane already exists, only the wiring is missing.
- **Effort:** S. **Magic-frame impact:** M — under the fault conditions this lane exists for, it both spams the console inside presented beats and keeps spending the arm ceremony instead of parking. **Risk:** low — the park pathway is already built and tested on the outer catch; this just feeds it the missing signal.

### 4. `tryPresentedCall` sites retry forever — deliberate serve-last, but the `parked` stamp they emit is never consulted

- **Evidence:** `tryPresentedCall` (2177-2190) latches only the *warn* per epoch; `run()` is still invoked on every presented pass, and each first-fault stamps `noteLaneFault(state, 'presentedTail.'+label, true)` — the `parked = true` flag — yet no code path reads `parked` for these lanes. A permanently-faulting tail site (e.g. a structural getter corruption in `frame-membrane`) pays one exception + unwind per presented frame for the epoch (~µs-class per throw, plus the stamp churn at first-fault).
- **Mechanism (hunt c — fallback audit):** I enumerated all 36 belted sites' fallbacks (publish leg 26502-26588, prepareFrame 27201-27375, fence-stats 25398): `keylight-frustum`/`shadow-follow`/`shadow-refresh-schedule` → `false` (legal: serves last map state), `shadow-cast-radius` → `_frameShadowCastRadius || SHADOW_ORTHO_EXTENT` (legal, conservative), `active-shadow-camera` → `this._activeShadowCamera` (legal: last-good or null is the type's own empty value), the 20+ side-effect sites → `undefined` (skip-this-frame, stale state is the designed degrade). **No illegal-stale fallback found.** And no site needs bounded-retry-*instead-of*-serve-last: the retry-every-frame semantics is strictly better than parking (self-heals without an epoch flip).
- **Residual:** the cost is one throw per frame under permanent fault — negligible — but the `parked: true` claim in `laneFaults` is metadata that lies (nothing parks). Either (a) serve the flag honestly by skipping `run` after N faults/epoch and clearing on epoch flip, or (b) drop the `true` arg — the faults counter alone carries the signal. (a) adds a skip path to 36 sites' semantics for a µs saving; (b) is a one-word honesty fix.
- **Effort:** S either way. **Magic-frame impact:** L. **Risk:** trivial for (b); low for (a).

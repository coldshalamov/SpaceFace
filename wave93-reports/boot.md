## Findings (ranked)

### F1 — post-opening rescan collect never arms the node wallet: unbounded subtree census inside "paced" chunks — effort S, magic-frame M, risk L

Evidence: `src/render/renderer.js:15594` mints `unstagedCollectBudget = {remaining: SHADOW_DEPTH_PASS_NODE_CAP}` and the first collect loop consumes it correctly (`15595-15598`: 5th arg + `unstagedPart === UNSTAGED_COLLECT_OVER_COVER → break`). The rescan loop at `15669-15675` — added the same wave for unlatch-into-join — calls `collectUnstagedShadowCasters(renderer, rescanDelta.slice(i, i + 512), scene, freshDepthLightSig())` (`15671-15672`) with FOUR args → `nodeBudget` is `undefined`/`null` (`shadowDepthAdmission.js` 5th-param signature, OVER_COVER machinery ~519-524). The wallet is in scope, unused. `rescanDelta` is the late-joiner set — `lateEntities + roots + uncompiled + rosterPrewarmRoots + rosterPartCatalogRoot` (`15624-15637`) — i.e. fat authored boundaries, not leaves; each root's `collectPotentialShadowCastSubjects` subtree census lands atomically inside its chunk, up to `rescanPasses < 3` (`15615`).

Mechanism: the W92 boot-F3 fix covered the primary collect only. The rescan comment (`15620-15622`) states these legs "used to pay the whole traverse set atomically inside a presented frame" — the rescan fires on flight-mode joiners too, so a fat packaged boundary's flag census still lands atomic inside a presented frame, exactly the class the wallet was built to pace. Chunking by subject COUNT (512) bounds roots-per-await, not nodes-per-await.

Fix sketch: pass `unstagedCollectBudget` (or a fresh `{remaining: SHADOW_DEPTH_PASS_NODE_CAP}` per pass) as the 5th arg and mirror `15598`'s `=== UNSTAGED_COLLECT_OVER_COVER → break`. MUST pair both — the sentinel is a STRING (`UNSTAGED_COLLECT_OVER_COVER = 'sfUnstagedCollectOverCover'`, `shadowDepthAdmission.js:367`); adding the wallet without the guard leaves `unstagedPart.length > 0` truthy on the string and `unstagedRescanDelta.push(...unstagedPart)` spreads it into 27 chars of bogus subjects. Over-cover subtrees never mint marks → re-collect on next admission, no coverage loss — same contract as the primary loop.

### F2 — post-opening `driveDepthCompile` retries `stale` but drops `aborted`: a mid-drive session close leaks the whole depth ceremony onto per-root arm fallbacks — effort S, magic-frame M, risk L

Evidence: `renderer.js:15573-15587` — the bounded attempt loop retries only `depthResult.stale === true` (15579); every other result returns on attempt 0. `shadowDepthAdmission.js:704-712`: the staging session is a single per-renderer WeakMap slot — a concurrent producer minting under a different sig/epoch/light closes the held session. The arm's leg drive (`~25388`, fire-and-forget via `armCallbackAfterPresent`) shares that slot and can interleave while the post-opening drive is suspended on `await postPace()` (`15582`). Resuming on the closed session yields `{skipped:true, aborted:true, reason:'session-closed-mid-drive'}` (884-886, 1016-1018, propagated at 748) — which the loop returns as final.

Mechanism: an aborted post-opening leg mints zero depth marks for the whole `unstagedDepthSubjects` cohort. Those casters reach first live shadowed draw unlinked — the in-round cold-link the admission exists to prevent — then heal through the slow path: checked-sync `collectGate` re-collects per root → withhold → `_queueShadowDepthStage` → per-root arm legs across presented frames. One staged leg behind the loading shell becomes N small legs in-round. Self-healing, but the work migrates onto presented beats in exactly the window the ceremony was built to hide. Adjacent to the DOCUMENTED-deferred hitches F5 (mint-thrash needs shared-session finalization) but distinct: this needs no finalization machinery — only a retryable-abort term in the existing bounded loop.

Fix sketch: treat `depthResult.aborted === true` (key on `reason === 'session-closed-mid-drive'` if map-disabled retries are to be skipped) like `stale` — break to the re-mint at 15584-15585 and retry under the fresh epoch, sharing the same ≤4 attempt counter so a persistent thrash defers to the next caller exactly as light-census churn does. Each retry re-mints a fresh session against the live scene; safe because a competing mint is bounded (arm legs ≤128 meshes → ≤4 sub-batches) before the slot is free. When the setting is OFF (`forceEnable:false`) an aborted leg is already a correct no-op — the extra ≤4 re-aborts are cheap, or gate the retry on `forceEnable === true`.

### F3 — `UNSTAGED_COLLECT_OVER_COVER` wallet path untested: the string-vs-array sentinel is a trap for the F1 fix — effort S, magic-frame L, risk none

Evidence: `test/shadow-depth-admission.test.mjs` drives `collectUnstagedShadowCasters` wallet-less only (`530`, `536` — array returns); W92's new test (`609-650`) pins `session.close()` mid-`sliceSteps` → `aborted:true` but nothing passes `nodeBudget`. `UNSTAGED_COLLECT_OVER_COVER` is a string constant (`shadowDepthAdmission.js:367`) returned where callers expect an array — a naive "add the wallet" edit at 15671 without the `===` guard spreads the sentinel into the subject list (per F1 fix sketch). A fixture asserting `collectUnstagedShadowCasters(r, [fatRoot], scene, sig, {remaining: 0}) === UNSTAGED_COLLECT_OVER_COVER` pins both the sentinel contract and the correct guard shape before the F1 edit lands.

## Residual enumeration — hunt items (a)–(e)

**(a) env A→B→C queue ordering — proven sound.** `queueSceneEnvMapRebind` pushes `{iter, disposeTarget}` FIFO (`26884-26888`); `drainSceneEnvRebindQueue` only ever steps `queue[0]` and `shift()`s it on `step.done` (`26897-26905`) — the A→B walk completes fully before the B→C walk begins. The per-material predicate `material.envMap === previousEnvMap` (`26839`) composes into last-write-wins: A→B rewrites every `===A` material to B; the queued B→C walk then rewrites every `===B` to C; a material minted mid-queue binds the current env (C) at admission and is `===C` — untouched by either walk. Disposed-target sampling is impossible: `disposeTarget.dispose()` fires only after the walk's exhaustive coverage (scene + `collectPreparedAuthoredCompileRoots` + every boundary's `wholeShipLodRoots`, `26862-26879`) has already rewritten all matches — a material can hold `===A` only if unvisited, and `dispose` waits for `done`. Scene-swap edge: a captured-scene iterator keeps walking the dead graph harmlessly; reparented nodes stay reachable via pushed stack entries; materials migrated into the new scene still carry the predicate chain. No reset path clears the queue — nothing strands targets. Sound; no action.

**(b) env-drain starvation — bounded, no starvation.** `head.iter.next()` at `26899` executes BEFORE the `now() >= deadline || pacedFrameSpend() >= PACED_FRAME_BUDGET_MS` break at `26907` — every `drainSceneEnvRebindQueue` call advances the queue head ≥1 generator step = up to 256 node visits regardless of ledger saturation (ledger full or the 4ms wall already blown still yields one slice). `serviceRenderMeshResidency` calls the drain unconditionally every presented frame (`2140-2144`, invoked at `23723` before the `holdLoadingGpu` gate) including `mode:'loading'` ticks. Worst-case dwell for one rebind entry ≈ ceil(sceneNodes/256) frames ≈ ~65 frames ≈ ~1.1s on the ~16.5k-node census — bounded; real rebinds share the budget with other paced work but never starve. Caveat: a backgrounded/tab-hidden render loop parks a live undisposed `disposeTarget` — benign (it is never sampled as disposed; drain resumes on the next present).

**(c) aborted-propagation gaps — clean.** Drive-result consumers at `9555`, `9812`, `11628`, `13164`, `13532`, `14616`, `15551`, `25388` read `skipped` into diagnostics only (`recordOpeningCookStep`/`depthSweepOutcome`/`rockPools.depth`). The ONLY verdict renderer is the arm `.finally`, which now requires `legDriveFailed !== true && legAborted !== true` (`25420-25421`). The new map-disabled early-out (`893-896`) can mint no park: the only park sites are the gated `.finally` verdict and the collect-side over-cap escalation (flag census — render-independent). No consumer parks undrawable on a skip-without-abort read. Enumerated; nothing open.

**(d) remaining atomic blocks on the boot path, ranked by node count:**
1. Rescan `collectUnstagedShadowCasters` — unbounded subtree census per delta root, ≤3 passes — F1.
2. `lightCensusSignature(scene)` (`shadowDepthAdmission.js:395-418`) — atomic whole-scene traverse per mint (~16.5k nodes); amortized to ~1/pass (`freshDepthLightSig` 15545 re-mints only on epoch drift; drive retry re-mints; `_shadowCensusForFrame` memoized per sync pass). Largest remaining unbudgeted single-call walk; a steps twin is feasible (signature fold is order-sensitive but `traverse`'s preorder DFS replicates exactly with an explicit stack).
3. `beginDirectionalShadowWarm` `scene.traverseVisible` (precompile.js ~:865) — whole-visible-scene walk per warm; both call sites (`:328` incremental cook, `:845` resident warm) run behind the loading shell — bounded by context.

All other boot/cook scene-scale walks already run stepped: `updateMatrixWorldSteps`, `collectNeverLinkedSceneRootsSteps`, `collectInstancePoolCompileRootsAndSubjectsSteps`, the keepGpu reattach/reconcile pumps (`2210-2277`) under 4ms wall + `pacedFrameSpend` ledger (`PACED_FRAME_BUDGET_MS = GLTF_COMPILE_FRAME_MS = 4`, decodeTaskBudget.js:307).

**(e) retry receivers — enumerated.** Four retry classes exist today: (i) arm `.finally` — aborted/failed legs mint no verdict → deferred roots stay in `pending`/leftover → next arm retries naturally (bounded cost per arm, unbounded in wall time — by design); (ii) denied park — `sfDepthUndrawableCycles` ×2 backoff capped 8 (W71 ladder); (iii) over-cap collect — `depthNodeScale` escalation ≤8 → park without `denied` → drift recheck re-offers; (iv) census drift — `stale` → bounded re-mint ≤4 inside both `driveCompileShadowDepthPipelines` (`529-556`) and `driveDepthCompile` (`15573-15587`). **`aborted` has no retry receiver**: the arm self-heals via pending (re-offered each arm — cheap, fine), but the post-opening drive returns the abort to a diagnostic-only consumer, dropping the whole cohort to per-root fallback (F2). That asymmetry is the only place a transient abort is not retried at its call site.

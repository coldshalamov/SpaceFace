## 2. Doc-line recommendations (no code change from this lane)

- **R7 — `detachOnMark` dormancy:** `assetLoader.js:1731` reads `scene.userData.authoredReadableFallbackLayer`, but `scene` is always a fresh `gltf.scene` — the flag is only minted mount-side on wrapper roots (`partsLibrary.js:10175+`). The N3 comment at `:1729-1731` says "may already be" without pinning that the flag is effectively dormant today; the live fallback-layer detach path is the W140-G3 resident-gated sweep (`partsLibrary.js:10196-10198`, comment pinned `:10185-10190`). Recommend one doc line at `:1731` noting dormancy so a future stamper doesn't silently arm eager detach without residency proof.
- **R8 — `canPoolRenderPackageShipMesh` armed-object exclusion:** `partsLibrary.js:14367-14368` rejects sources carrying non-prototype `onBeforeRender`/`onAfterRender` (i.e. residency-ledger-armed). Unreachable today — pool sources come from package template `planEntries` (`:14416-14420`) and `armGeometryGpuResidentLedger` only ever wraps live drawables, never template sources. No comment pins the intent; recommend one so the check isn't read as dead code and stripped.
- **Facade arming noise:** `startupGpuResidency.js:224-226` mints `Object.create(object)` tier facades pushed into the drawable collect; `armGeometryGpuResidentLedger` arms them (each is a fresh object, so the `residentLedgerArmedObjects` WeakSet dedupe never hits; the hook never fires since facades aren't rendered). Dead work, still harmless — `noteGeometryGpuResident` would no-op on unmarked `tierGeo` anyway. No action.

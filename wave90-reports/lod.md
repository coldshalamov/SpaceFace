## 2. Ranked findings

### F1 — Undrawable-forever park is dead code; undrawable casters spin collect→drive→requeue forever
- **Evidence:** renderer.js:25241–25245 — the park gate is `allOffered && !legDeferred`. `legDeferred` is set unconditionally at :25149 whenever `unstaged.length > 0`, and `leftoverByRoot` (:25193–25202) is only non-empty when a leg was dispatched (leftover ⊆ `unstaged` ⇒ leg ran ⇒ `legDeferred === true`). `!legDeferred` is therefore always false where a leftover exists — the park at :25246–25273 is unreachable. Worse, the audit runs synchronously right after `driveCompileShadowDepthPipelines` is *dispatched* (fire-and-forget, .catch/.finally at :25169–25177); the drive's marks land presents later, so every offered mesh evaluates `!casterDepthMarkCurrent(mesh, lightSig)` as a "leftover" — the audit can't distinguish in-flight from undrawable.
- **Mechanism:** a mesh that can never mark (geometry-less caster, unreadable layer, material-invisible) is re-collected once its drive's `.finally` clears `_deferredDepthStageRoots`, re-offered to a new drive, draws nothing again, requeues — a perpetual ~every-2-3-arms cycle per undrawable root, each cycle paying up to `SHADOW_DEPTH_PASS_NODE_CAP`-scaled collect + a session slice. The parking machinery W77 built to kill this spin never engages.
- **Fix sketch:** move the leftover audit into the drive's `.finally` (marks have landed by then): for each deferred root, re-check `casterDepthMarkCurrent` per offered mesh; roots whose whole offered set came back unmarked take the park path there (parkedMap.set with the same recheck/lightSig/oqX/depthNodeScale fields). The arm-side audit then only needs the capped-remainder requeue, not the park verdict.
- **Effort:** S–M. **Magic-frame impact:** M (perpetual background burn + bounded collect spam; never a hitch spike, but never converges — also inflates every later arm's collect window). **Risk:** low — the park bookkeeping already exists and is exercised by the collect-abort path; the change relocates a check, not the data model.

### F2 — Withhold-exemption traverse is unbounded; census re-sign and ortho-cell drift release every parked root in one pass
- **Evidence:** renderer.js:24849–24856 — `traverseDeferred` only defers `allowCast !== false` roots; withhold verdicts (`syncOpts.allowCast === false`) are exempt and traverse immediately. The exempt count per pass is not bounded by `SHADOW_DEPTH_PASS_COLLECT_CAP` — over-covered roots *become* withhold verdicts and still traverse. Mass-release sources: (i) `parkedEntry.lightSig !== this._shadowCensusForFrame()` at :24697–24699 — any `noteShadowCensusLightMutation` re-signs the census and releases EVERY parked root in the same pass; (ii) ortho-cell drift at :24700–24707 — `parkedEntry.oqX/oqZ` vs `keyLight.target.position` — the shadow ortho follows the camera, so every ~half-extent translation releases the whole parked cohort at once; (iii) any mass dirtySeq burst. Each released/over-covered root pays its own `syncShadowCasterPolicy` O(subtree) traverse inside the pass.
- **Mechanism:** station-dense scenes with tens of parked roots convert one census re-sign (a pooled-light mount/dispose) or one ortho cell crossing into N exempt whole-subtree flag writes in a single presented frame — a recurring mid-flight brick on the largest scenes. The `state.dirty`-gated early-out in shadowCasterPolicy.js:254 bounds *steady-state* re-pays but not transitions (the release itself re-dirties).
- **Fix sketch:** the cheap 80%: pure *drift* releases (`parkedReleaseOnDrift`, no dirtySeq bump) into a withhold verdict don't need the traverse — the parked root's casters are already cold (park = castBand-0 withhold state); skip `syncShadowCasterPolicy` and re-stamp bookkeeping only. For genuinely dirty transitions the flag writes are real work — bound the remaining stack by sorting exempt traverses smallest-subtree-first and letting the over-budget tail defer one pass while keeping `castBand 0` already stamped (cold-link preserved because the flags never re-warm). Est. `SHADOW_ORTHO_EXTENT` cell ≈ 320 WU makes (ii) a per-few-seconds event under thrust — also consider hysteresis on the parked oqX/oqZ compare (e.g. release only outside a margin) to convert the cliff into a trickle.
- **Effort:** M (drift-skip is S; the tail bound needs a node budget shared with the collect path). **Magic-frame impact:** H on station scenes, M elsewhere. **Risk:** medium-low — the drift-skip must verify flags truly were never re-warmed (parked roots that gained meshes get a dirtySeq bump and take the normal path — that gate already exists at :24696).

### F3 — `detachBoundaryResolvingMarker` pays a whole-boundary traverse inside every authored commit
- **Evidence:** visualOverrides.js:619–630 — every commit seam walks `boundary.traverse` to purge `authoredResolvingMarker`-tagged stragglers, including boundaries where no marker was ever minted. Markers only ever mount via `boundary.add(marker)` (:468) — direct children; `data.resolvingMarker` tracks the minted one and `data.authoredResolvingMarker` is stamped at mint (:470).
- **Mechanism:** O(boundary subtree) — authored place/station roots are the largest trees in the game (~1–3k nodes) — inside the atomic publish seam on every commit, to catch a reparent case that has no known producer.
- **Fix sketch:** early-out when `!data.authoredResolvingMarker` (never minted ⇒ nothing to purge); when minted, check `boundary.children` tags plus the tracked marker's subtree only — the straggler-in-authored case is already a broken-marker scenario the commit replaces anyway.
- **Effort:** S. **Magic-frame impact:** M (per-commit, every authored mount). **Risk:** low.

### F4 — Arm's `lightSig` mint has no paired epoch; drift inside [mint → drive first call] escapes `censusStale`
- **Evidence:** renderer.js:25050 mints `lightSig = lightCensusSignature(scene)`; the drive opts at :25157–25169 pass `lightSigOverride` but no `lightSigEpoch`. `driveCompileShadowDepthPipelines` mints the epoch at its own first call (renderer.js:532–533). A `noteShadowCensusLightMutation` landing in the gap → epoch already advanced at drive mint → `censusStale()` (shadowDepthAdmission.js:577) passes → the ceremony stages and marks under the pre-mutation sig.
- **Mechanism:** marks stamped under a sig the live census can never produce — `markCastersDepthStaged` queries always miss; the offered casters stay withheld until the next arm re-collects and re-mints (self-heals in ~1 arm cycle). Wasted ceremony + an extra dark window, only when a light mutation lands in the ~ms-wide collect/dispatch window — pooled light activity makes this rare but real.
- **Fix sketch:** capture `shadowCensusEpoch()` beside the :25050 mint and pass it as `lightSigEpoch`; the existing stale-abort then catches the gap and the bounded retry re-mints both. One-line plumb.
- **Effort:** S. **Magic-frame impact:** L. **Risk:** low.

### F5 — Residual unstepped whole-subtree walks inside commit/settle seams (tail class)
- **Evidence:** `suppressAuthoredReadableSilhouette` authored-root traverse (partsLibrary.js:9444), `markReadableFallbackLayer` fallback-root traverse (:9429), `collectPresentationTextures` mesh.traverse on release seams (renderer.js:8918), `ensureStandardSockets` hull.traverse (partsLibrary.js:15644), `installStationOpaqueDepthPrepass` station-root collect (:4936 — inside paced compose legs, lower rank), `specializeClaimRelayOpaqueMaterials` (:4669 — one placeId), `getPooledNavLightSources` memoized census (renderer.js:6978), env-rebind traverses (:26605–26620 — rebake-only), `socketWorldPose` memoized socket find (:25804), `collectNeverLinkedSceneRoots` (:8150 — behind-shell caller; chunked twin exists).
- **Mechanism:** each is an atomic O(subtree) walk in a seam; individually ~100–3k nodes — none brick alone, but they stack inside fallback/settle commits on the same frames the arm machinery is trying to keep light.
- **Fix sketch:** fold the three fallback-settle walks (markReadable, suppressSilhouette, texture collect) into the paced commit legs that already drive the surrounding work, or mint Steps twins matching the W82 pattern; leave the memoized/rare ones documented.
- **Effort:** M (several sites). **Magic-frame impact:** L–M aggregate. **Risk:** low.

## 3. Lane hunt results (a)–(e)

- **(a) withhold-exemption starvation — CONFIRMED UNBOUNDED.** See F2. Exempt traverses per pass = #roots reaching a withhold verdict; over-coverage *converts to* a withhold so the collect cap does not bound them; only the identical-state early-out bounds steady-state re-pays. Worst-case = mass-release storms (census re-sign, ortho-cell crossing) × subtree size.
- **(b) census-epoch bump coverage — COMPLETE, no gap found.** Live-scene lights are: the static sector rig (minted once at scene init :9142–9145, never removed — tint/intensity changes don't move the sig), the key light (change-gated bump on every castShadow write :25565, :25599, :25654), pooled lights (weaponLights dispose :105–113, flightOverhead dispose :59–63, disposeObject heldLight :26689 — one bump per light-holding dispose), precompile stand-in mounts (precompile.js:180/:198). Authored content **cannot carry lights**: the parts contract rejects embedded lights/cameras (assetLoader.js:1510–1511) and render packages throw on `isLight` (assertRigidPlanNode, renderPackageLoader.js:626–639). Detached disposers (`disposeDetachedPackagedGroup`, `disposeDetachedObject(Steps)`, `disposeDetachedPlaceFallback(Steps)`) operate on trees never in the live census — correctly silent. Pooled-mesh returns carry no lights. Preview/lab scenes are outside the census scene. Pool contract never toggles light `visible` mid-flight (intensity-only — the relink cost this avoids is documented).
- **(c) mark sig vs session sig — consistent; one mint gap (F4).** Session reuse keys `sig === markLightSig && epoch === shadowCensusEpoch()` (shadowDepthAdmission.js:592–600); marks are stamped under `options.lightSig` which is the session's own mint sig — the pair can't diverge internally. Stale retries re-mint both override+epoch (renderer.js:545–551, bounded ×4). The only path minting under a sig the query can never hit is the un-paired-epoch gap in F4 — self-healing next arm.
- **(d) remaining whole-subtree traverses in commit seams — ranked in F3 + F5.** Largest is F3 (full authored boundary per commit).
- **(e) OFF→ON queue drain — bounded.** `_stageShadowDepthOnSettingEnable` routes all work to queue/stamp/bookkeeping (no inline sync); each arm is deadline-bounded (`SHADOW_DEPTH_ARM_COLLECT_MS`/`_RESTORE_MS` = 4 ms each, `SHADOW_DEPTH_ARM_MESH_CAP` = 128) and re-arms while `pending.size > 0` (:25368–25374); per-root collect aborts escalate `depthNodeScale` ×2 (cap 8) then park with census+ortho-keyed release; ledger-skips bound (`SHADOW_DEPTH_LEDGER_MAX_SKIPS` = 2) forces progress under a saturated paced budget. Starvation order: nearest-first re-sort per arm — far roots can wait behind continuous nearer arrivals, but withheld flags keep the cold-link contract for waiters; sound, not FIFO-fair (L residual, not a finding).

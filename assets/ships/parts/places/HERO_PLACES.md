# Place hero justification

Informative only — not a lease, dispatch order, or acceptance decision. Live reuse counts belong to
the atlas and manifests; re-measure before treating a row as current.

The honest argument for a hero GLB is **silhouette collision**, not abstract importance. Ordinary
debris, hulks, claim rocks, and lane beacons should keep shared silhouettes.

Ordered by argument strength:

| Place | Why bespoke work is justified |
|---|---|
| `station_helios` — Helios Station | Starting station, every early dock, tutorial anchor. Currently a shared `place_station_trade_hub` silhouette. |
| `station_tethys` — Tethys Trade Hub | Canonical-route destination. Currently shares Helios's exact silhouette — the worst collision in the set. |
| `poi_wormhole` / Veil → Ashfall | Sole non-reciprocal atlas gate. Unique traversal currently reads as ordinary furniture. |
| `poi_memorial` — Memorial Array | Starting-sector narrative anchor currently rendering as `place_station_billboard`. |
| `station_sker` — Sker Bazaar | Reputation-gated faction hub currently one of many `place_station_blackmarket` instances. |
| `poi_boss` — Boss Arena Signal | Story climax currently a `place_nav_buoy`. |
| `station_veil` — Research Station Veil | Gates the tech-locked wormhole; currently a repeated research station. |
| `station_ashcache` — Ruined Cache Station | Endgame-sector anchor currently a blackmarket repeat. |

## Quality / modifications-required note

**Not equivalent** to the preferred re1monsen “Space Station” CC-BY hero donor (~170k tris, metalness PBR, 4K textures).

This pack is a **stylized low-poly modular kit** (~97 modules; aggregate ~8.7k tris across all GLBs). Suitable for layout/blockout/kitbash only.

Required before any Helios use:

1. Compose modules into a station silhouette at game scale.
2. Author or bake real PBR materials (kit has no 4K PBR set).
3. Axis/scale check for Three.js Y-up.
4. LOD / batch / instance strategy for runtime.
5. Keep this path as third_party donor only until an intentional authoring pass.

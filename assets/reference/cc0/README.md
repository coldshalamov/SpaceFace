# CC0 reference — not runtime

These files are source for a quality pass. Nothing in here is loaded by the game.
`assetLoader`, the sample library, and the sky plates do not point here. Promote a
graded result into the live material or audio path. A raw photo on a hull, or a
Kenney laser in place of an authored weapon, is a failed promotion.

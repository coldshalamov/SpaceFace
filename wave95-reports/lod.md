## Ranked findings

### F-1 — The pass cap counts calls, not traverses: clean early-out calls drain `SHADOW_ROOT_SYNC_PASS_CAP`, starving every later dirty root's withholds and policy syncs indefinitely

- **Evidence:** `renderer.js:25057-25060` — `_shadowRootSyncPassCount++` runs for every un-scoped, non-deferred, non-drift, non-parked *call*; no work-existence check. `shadowCasterPolicy.js:256` — the walker's early-out (`!state.dirty && lodLevel === nextLodLevel && castBand === nextCastBand` → `return null`) means a clean call pays zero traverse yet still consumed the slot. Callers: `renderer.js:22693-22699` inside the `for (index < query.visibleCount)` loop (`:22589`) — every visible ship/station/place root every presented pass — plus mounts (`:22008`, `:22190`, `:10321`) and the un-scoped swap (`:9258`). Counter resets once per presented pass on `_viewSyncSeq` (`:24934-24943`, bumped `:22408`). Iteration order is stable slot order.
- **Mechanism:** in any presented pass with >8 eligible callers — routine in a populated sector (player + AI ships + station + places, let alone a mount/commit burst competing for the same slots) — the first 8 *callers in slot order* consume every slot whether or not they have work. A dirty root at position ≥9 defers on every pass: it never mints a stepped walk (the mint call is inside the `!traverseDeferred` gate), so `hadParkedWalk` can never rescue it, and `state.dirty` never clears (`finish` is the sole writer). Consequences: withhold verdicts on late roots never apply (the unsafe subset is F-2), and ordinary dirty roots keep stale cast policy indefinitely — a post-mount subtree attach keeps mount-default flags, i.e. wrongly-live unlinked casters drawing into every presented shadow refresh (cold link + possible in-frame program mint) or wrongly-dark shadows. Pre-W94 this same counting existed, but only castable mints deferred — starvation delayed benign policy refreshes. W94 moved cold-link-critical withhold verdicts behind the counter, so the accounting flaw now starves protection work.
- **Fix sketch:** don't consume a slot when the walker would early-out. Hoist a predicate equivalent to the walker's early-out above the increment — e.g. a new export `shadowCasterPolicyNeedsSync(root, lodLevel, allowCast)` in shadowCasterPolicy.js (`state.dirty || state.lodLevel !== nextLod || state.castBand !== expectedBand`, computed after `syncOpts` resolves) — and when it is false, skip the traverse call entirely (outcome-identical: the traverse is a no-op; it also kills the `parkedMap.set`/`delete` churn every clean near root currently pays per frame — the F-3 micro-item). The preamble bookkeeping (parked recheck, collectGate collect, `withheldMeshes` flags, queue mints) sits above the gate and must stay unconditional.
- **Effort:** S-M (predicate hoist is small; it must mirror the early-out exactly under the *resolved* syncOpts — expectedBand follows `syncOpts.allowCast !== false`, not `opts`). **Magic-frame impact:** H — unbounded starvation of withhold/policy work on late-slot roots in busy frames. **Risk:** L-M — a predicate mismatch would either reintroduce the counting bug or skip real traverses; the predicate is a two-clause read of exported policy state.

### F-2 — Deferred withholds leave never-flagged unstaged casters live: over-cover / no-cache / settings-enable queue verdicts defer with zero per-mesh flag writes

- **Evidence:** `traverseDeferred` (`:25052-25056`) — W94 removed the `syncOpts.allowCast !== false` exemption (present at `33e18718a`) so withhold verdicts now defer. The only synchronous flag writes below the gate are the `withheldMeshes` loop (`:25115-25140`), and `withheldMeshes` is set only when the subset collect succeeded (`:24983-24989`). The uncovered mints: over-cover (`:24993-24995` — `syncOpts = { allowCast: false }` with *no* unstaged set — deferred → nothing flags → queue still lands at `:25142-25152`), the band-1 `selfDirty && queued` no-cache branch (`:25013-25019`) and the plain `queued` catch-all (`:25020-25025` — its own comment: "it must never reach the live sync below. Withhold again" — under defer the withhold does not happen), and the settings-enable `queueOverCover` path (`:25730-25760`) whose comment documents the broken assumption verbatim: "the very next presented sync applies castShadow=false (**cap-exempt**) before the shadow refresh draws." Cap-exempt no longer exists.
- **Mechanism:** a root whose genuinely-unstaged casters were never per-mesh flagged keeps `castShadow=true` across the deferred pass's presented shadow refresh — unlinked depth variants draw in-frame: the cold-link class the whole withhold machinery exists to prevent, plus a possible depth-variant program mint inside the presented refresh (DRAW-TIME-MISS hitch). Window is ≥1 presented frame per defer; under F-1's permanent starvation for late-slot roots it is unbounded. Transient trigger without F-1: any pass where collect cap/node budget and traverse cap co-saturate — mass ortho-entry, sector-entry dirty burst, shadows-OFF→ON flip in a busy sector — i.e. exactly the bursts the caps were built for.
- **Fix sketch:** predicate the defer on *coverage*, not verdict: a withhold verdict may defer only when every genuinely-unstaged caster in scope is already flagged — concretely `traverseDeferred &&= !(syncOpts.allowCast === false && !coverageKnown)` where `coverageKnown = (withheldMeshes != null) || _withheldDepthCasters.has(root)` (cache presence proves a prior applied withhold's flags stand — they are never flipped back except by an atomic restore). Uncovered withholds must pay the atomic traverse — the same per-dirty-generation cost pre-W94 always paid (the walker early-outs once flags are stamped, and `dirtySeq` stamps bound re-mints). A *stepped* withhold walk is not a substitute: tail meshes stay unflagged across presents and the withhold-before-present ordering is what makes the cold-link proof work.
- **Effort:** S-M. **Magic-frame impact:** H — this is the pop-in/hitch class inside presented frames, worst exactly during bursts. **Risk:** M — misjudging `coverageKnown` either re-introduces unbounded atomic withholds (the cost the cap was meant to bound) or leaks an unflagged caster; the two-clause check above is cheap and exact.

### F-3 (minor, subsumed) — `parkedMap.set`/`delete` churn per clean call

- **Evidence:** `driveShadowPolicySteps` (`:27010-27051`) mints a `_policyStepsParked` slot (`parkedMap.set(root, slot)` at `:27029-27033`) and immediately deletes it when the generator's first `next()` returns `done` (`:27034-27038`) — which is every clean call, since `makeShadowPolicyWalker` returns null and `syncShadowCasterPolicySteps` returns `false` on the first step. So every clean near root pays a Map insert+delete+slot-object alloc per frame.
- **Mechanism:** pure allocation churn inside the presented pass; no correctness impact. Rolls into F-1's fix for free (skipping the stepped call when the walker would early-out eliminates the mint entirely).
- **Effort:** none separately (comes free with F-1) · **impact:** L · **risk:** none.

## Enumerated residuals (lane hunts a–e + the starvation question)

- **Starvation (top question): YES, a deferred verdict's root can starve.** The catch-all does re-mint the verdict each pass — but under F-1 the cap never drains to it: the same first-8 callers re-consume every pass. Non-queued dirty roots at late slots starve indefinitely; queued roots still converge via the arm (the pending map is visibility-blind; 4 ms arm + restore deadline per present, `:25217+`/`:25560+`) — but only after the unflagged window F-2 describes.
- **(a) Deferred withhold partial-flag window — subset case safe, uncovered case is F-2.** When the subset collect succeeded, `withheldMeshes` is the *complete* unstaged set (the collect is budget-complete or returns the OVER_COVER sentinel — `:24958-24969`), so every unlinked caster is flagged synchronously and staged members keeping `castShadow=true` one extra frame is correct (their depth variants are linked). The depth-variant unlink hazard survives the defer only where no per-mesh coverage exists: over-cover verdicts, `band===1 && selfDirty && queued` without a withheld cache, the plain `queued` catch-all on a never-flagged root, and the settings-enable `queueOverCover` roots — F-2.
- **(b) `needsAtomicOut` mid-burst bound — enumerated, no storm class.** The sole un-scoped `preCountRoot` caller is `onAuthoredAssetSwap` (`:9256-9260`); the packaged caller (`:11281-11284`) passes `syncScope` → `scopedSync` → cap-exempt by construction and doesn't consume. Swap commits ride the frame-serial authored-upgrade lane (`admitNextUpgradeJob` per rAF), so ≈1-2 atomic traverses+fused preCounts per presented pass worst case — and counting them is legitimate since they pay real traverses. The pre-W94 inversion (deferred `preCountRoot` → unbounded `countShadowReceivers` fallback) is genuinely closed.
- **(c) Parked-resume min-1 floor — enumerated, by design, bounded by burst size.** `hadParkedWalk` exempts both the count cap (`:25052-25056`) and the spent-wallet mint gate (`:25072`), and `driveShadowPolicySteps` steps `iter.next()` *before* consulting `deadlineFn` (`:27033-27044`) — so K suspended castable walks each pay one ≤256-node slice (`shadowCasterPolicy.js:391`) per presented pass, unmetered against `_policyPassDeadlineAt`. The wallet can't bound it because half-applied flag sets must finish; K is bounded by the dirty-burst population and resume order follows the caller's slot iteration. No wedge: each call still advances ≥1 slice, and completion clears via `finish`.
- **(d) `_policyStepsParked` on hidden/culled roots — no driver while invisible, no wedge.** The checked sync runs only inside the `query.visibleSlots` loop (`:22589+`); a *non-queued* parked walk on an invisible root waits until re-visibility (resumes via `:22698`), detach (reaped by every seam: unbind `:20649`, detached-owner teardown `:20874`, `clearAllMeshes` `:20939`, W94's arm sweep `:25217`/`:25230`, mid-arm detach `:25576`), or queueing (the arm drives it — pending map is visibility-blind). Dirty latch holds throughout (`finish` never ran → `state.dirty` set → re-entry completes or re-collects); mid-state flags sit on an invisible root so nothing draws. Residual = the suspended iterator's node-stack refs pinned for the hidden lifetime — bounded by subtree size; W93 adjudicated this benign, W94 added the sweep reaps, verdict stands.
- **(e) "Deferred withhold leaves its parked castable walk alive" — unreachable as posed; cleared.** `traverseDeferred` requires `!hadParkedWalk`, so a deferring root *by construction* has no parked walk at that moment; while queued, every re-entry mints `allowCast:false` (the band/queued clauses at `:24997-25025` force it), so the withhold re-mints *atomically* on the first re-entry and kills any parked walk with `carriedDelta` carried forward (`:25095-25112`) — and since a parked walk makes `hadParkedWalk` true, a root holding one is *immune* to the verdict defer entirely (fairness asymmetry, not a defect). The only castable resume a queued root can see is the arm's post-stage restore (`driveShadowPolicySteps` at `:25620`, sig `1|1` matching a parked castable slot — resuming it *is* the intended restore: post-stage casters are linked, minted opts are castable); leftover/unmarked roots skip the restore and stay queued (`:25586-25597`). No resume path can write castable flags while a withhold is pending.

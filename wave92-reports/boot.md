## Findings (ranked)

### F1 — suspended drive + external session retire/zero-draw window lands false "undrawable" parks — effort S, magic-frame M, risk L

Evidence: `src/render/shadowDepthAdmission.js:1002-1004` (`sliceSteps` early-out returns `{skipped: closed, subjects: 0}` — a closed session reports a bare skip with NO `stale` flag), `742-749` (`compileShadowDepthPipelinesSteps` propagates `sliced.stale` but nothing else — no closed/aborted term reaches the drive), `733-741` (async path takes `sliceSteps`; closed → `{skipped:true}` all the way up), `renderer.js:25313-25372` (the arm drive's `.finally` renders the undrawable verdict whenever `legDriveFailed !== true` — a clean `{skipped:true}` return is not a throw, so every deferred root whose legSet meshes are still unmarked parks: `parkedMap.set` + `_withheldDepthCasters.set` + `sfDepthUndrawableCycles` ×2 backoff capped at 8).

Mechanism: W91's sub-batching opened a window that did not exist when `slice()` was atomic — the drive now suspends between ≤32-caster passes with the session still held in the per-renderer WeakMap slot. Three concrete mid-flight retire/zero-draw sources:

- **Concurrent producer re-mint.** The staging session is a single slot (`_depthStageSessions.set(renderer, heldSession)` at `731`). A second drive minting under a different sig/epoch/light closes the held session at `704-712`. The arm's leg drive (fire-and-forget at `25305`) and a cook-side `driveDepthCompile`/`warmOpeningShadowPipelines`/`driveCompileShadowDepthPipelines` call can interleave on the same slot; whichever loses the sig race resumes on `closed` → `{skipped:true}` → false verdict for its deferred roots.
- **Settings-OFF window.** The arm passes `forceEnable:false` (`25309`), so `runSlice` renders with whatever `shadowMap.enabled` currently is (`950`). If the setting flips OFF between batches, the staged pass produces zero depth draws → no marks land → `.finally` parks drawable casters as undrawable. OFF→ON recollect via `_stageShadowDepthOnSettingEnable` eventually fixes it, but the compounded backoff (`96-128 arms` × `2^cycle`, cap ×8 — the W71 ~96→768-sync ladder) can pin affected roots shadowless for seconds-to-minutes.
- **Teardown paths** (`disposeAdmissionShadowResources`, `_killDepthStageSession`) — mostly guarded: `clearAllMeshes` detaches roots, so the verdict's `!deferRoot.parent` check skips the park; and deferred roots re-enter `pending` synchronously in the arm's own restore loop (`25424-25426`), so the drain-empty kill at `25106` cannot fire while a drive is suspended. These two are safe today; the first two are not.

What the player sees: a burst of roots that were queued for a routine stage get classified as permanently unmarkable — they lose cast shadows (withheld flags re-sealed) and stay shadowless until the backed-off recheck or a dirtySeq/lightSig/ortho drift re-offers them. Self-healing but a real, distinguishable quality dip.

Fix sketch: plumb an `aborted` term through the skip shape — `sliceSteps`/`runSlice` already distinguish `skipped: closed`; have Steps propagate `{aborted:true}` (and in `runSlice`, when `forceEnable !== true` and `renderer.shadowMap.enabled !== true` before the render, return `{skipped:true, aborted:true, reason:'shadow-map-disabled'}`); the `.finally` treats `legDriveFailed || result.aborted` identically — leave roots queued, never park on never-ran.

### F2 — `replaceSceneEnvMap`: whole-scene + parked-root rebind, atomic, on the re-bake path — effort M, magic-frame M, risk L

Evidence: `src/render/renderer.js:26727-26762` (`scene.traverse(rebind)` + `collectPreparedAuthoredCompileRoots(scene)` traverses + per-boundary `wholeShipLodRoots` walks — all synchronous), fired at `21018` inside `_bakeEnv` whenever `previousEnvMap !== envMap`. Mechanism: the HDRI-promotion and source-change bakes can land on presented frames and sector-cook boundaries, paying a whole-scene traverse plus the parked/detached authored sets — the same O(~16.5k-node scene) walk the code at `19952` quantifies at ~11 ms on the owner's iGPU. First-bake (previous null) skips the rebind, so this is a re-bake-class block: sector swap, quality-source change, or the async HDRI upgrade landing mid-round.

Fix sketch: `rebind` is per-node idempotent and order-free — a chunked iterative twin (256-node slices, the existing collector convention) preserves semantics exactly; or fold the rebind into an existing stepped census pass.

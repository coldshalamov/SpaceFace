## Findings (ranked)

### F1 (S / M-H) — `composeYield`'s 48 ms timer fallback resumes at timer priority; publish legs land on the near side of the present during the >48 ms frames the yield exists to bound

- **Evidence:** `src/render/partsLibrary.js:11146-11162` — `requestAnimationFrame(fire)` + `setTimeout(fire, 48)`, `fire` resolves the promise directly. Contrast `yieldToNextPresent` (`src/render/startupGpuResidency.js:953-981`): same arm shape but `fire → scheduleTask(resolve)` = `postTaskAtBackgroundPriorityBounded`, and `armCallbackAfterPresent` (`src/render/compilePresentSlice.js:375-391`) does the same with the explicit comment that a timer-priority resume "races the compositor beat" (:352-358). Consumers promising post-present landing: "the publish leg lands in the next presented window" (:3463-3465, :4498-4500, :9930-9934, :9978-9981).
- **Mechanism:** tasks can't nest, so when a presented frame overruns 48 ms the expired timer task fires the moment the long task ends — *before* the next rendering update. The continuation (publish leg) runs pre-present inside that window: `touchAuthoredExactTarget` residual program link (:9989 — the comment's own "first presented bloom pass" hazard), `primeDrawnCullStamps` O(subtree) (:3489, :4524, :10006 — the measured-stamp early-out helps only once minted), pool-admission activation (:9993-9995), `installWholeShipLodFamilyController` (:9097). Hidden/occluded Electron: same resume at timer priority where no presents run. Headless (no rAF): `Promise.resolve()` microtask (:11161) — the whole paced tail collapses synchronous inside the calling task.
- **Fix sketch:** `fire` re-dispatches: `const fire = () => { if (fired) return; fired = true; postTaskAtBackgroundPriorityBounded(resolve, 0); }` (or delegate `composeYield` to `yieldToNextPresent`). No behavior change under healthy rAF — the rAF arm still wins; the change is only which queue the timer-resume lands in.
- **Effort S · impact M-H · risk: low** — every resume site already re-gates on stale/abort.

### F2 (S / M) — commit tails charge the yield wait as ledger spend (phantom debit)

- **Evidence:** restamp-after-wait is the convention everywhere else — `:4456` "Restamp after the wait — an inter-present pause is not ledger spend", `:10033`, `:4559`, `:4572`, `:4584`. Violated in all three publish legs: ship mints `commitLegStarted` :9924, crosses two `composeYield`s (:9935, :9982), debits `monotonicNow() - commitLegStarted` at :10020 — up to ~2 presents (~32-192 ms) charged as frame work. Place :4443 → :4501 → :4547. Cargo :3443 → :3466 → :3505.
- **Mechanism:** `PACED_FRAME_BUDGET_MS` = 4 (decodeTaskBudget.js). A single commit's phantom debit marks the resume frame ~10-50× overspent; every sibling slicer consulting `pacedFrameSpend()` — decode-runway kicks, mesh-build enqueue, presentation-drain and env-rebind drains, deferred-enter slices — stands down for the rest of that frame epoch. K concurrent commits in a spawn/sector-enter burst stack K × phantom → paced drains lose whole frames exactly during admission storms → decode runway stalls → the pop-in window stretches.
- **Fix sketch:** `commitLegStarted = monotonicNow()` immediately after each `await composeYield()` in the three commit twins — the resume frame should be charged the publish leg's real work only.
- **Effort S · impact M · risk: trivial** — bookkeeping only.

### F3 (M / M) — bus throw-through-cadence: a faulting listener pays throw+stack per emit for the whole session

- **Evidence:** `src/core/eventBus.js` `dispatchRange` :92-93, `drainEmitSlice` :403-404, `flushSlicedEmits` :354-355, `drainPresentationTail` :463-464 — all `catch → noteBusHandlerError`, which dedupes *logging* (8 verbatim + 1 s heartbeat per `tier|event|listenerToken`, :53-86). The `try/fn/catch` itself — Error construction + stack capture — still runs per emit.
- **Mechanism:** a persistently-throwing listener on a hot emit (`physics:impact`, `combat:damage`, `entity:spawned`) throws at emit rate for the session; dedup bounds only the console cost. The entity-view row lane solved this shape with `sfRowFaultedEpoch` (≤3 faults at ≥1 s spacing heal, then epoch park — renderer.js:2241-2263); the bus has no listener quarantine. `busListenerToken` already pins stable listener identity (:42-51), so a park set is cheap to key.
- **Fix sketch:** per-`(event, listenerToken)` fault stamp with the same cadence (3 faults @ ≥1 s heal → skip until epoch flip or re-registration); evaluate the skip inside the dispatch/drain loops before invoking. Order note: a skipped listener must not count against the slice budget — the drain loop's `ran` counter should not increment on a skip.
- **Effort M · impact M** (latent — pays only during a real listener storm, but then it's an unbounded per-emit in-frame tax). **Risk low-M** — quarantine changes a broken listener's observability (it stops running); epoch-scoped park heals on serial flip.

### F4 (S / M) — W118 driver-bank rollback double-disposes after `detach()`, and the two teardown orders diverge

- **Evidence:** `src/render/authoredMotion.js:364-380` — on a registered abandon the finally calls `detach()` (:371-373), which disposes all 10 drivers in order propulsion → tally → redKite → ilex → kilnback → scissorwake → towline → borrowedVoice → palletJack → mothlight → sable (:275-285), then the bank loop (:375-378) disposes all 10 *again* in creation order (sable 3rd, propulsion last).
- **Mechanism:** (i) double-dispose survives today only on incidental per-driver idempotency — `tallyThreeVisuals.js:115`, `latchNineVisuals.js:30` guard on `retired`; `ceresWorkfleetVisuals.js:210` is accidentally idempotent (`Set.delete` of an absent binding is a no-op); nothing enforces it, and `createLatchNinePlumeBatch` (:41) already shows the unguarded shape (`this.reset(); plume.dispose()` twice). A future non-idempotent banked driver silently double-frees. (ii) Two teardown orders for one driver set: any driver whose dispose reads a sibling's torn-down state (shared propulsion bindings map, pooled materials) sees a different interleaving on the abandon path than live detach.
- **Fix sketch:** when `detach()` runs, the raw bank loop is redundant — set `bankTransferred = true` (or a `detachRan` flag) inside detach's completion so the finally's raw loop becomes the pre-activate fallback only; equivalently stamp `driver._sfBankDisposed` per driver detach disposes and skip flagged entries.
- **Effort S · impact M** (cold path, but the guard contract is what's missing). **Risk: low.**

### F5 (S / L-M) — raw `console.warn` in per-commit tails where sibling twins use `warnOnce`

- **Evidence:** ship publish `partsLibrary.js:9991` (`authored publish touch failed`), `:10010` (`authored swap callback failed`), plus `:4588`, `:9222`, `:10058`, `:9525`, `:9791` — all raw console in per-commit/per-demotion catches, while the same functions' cargo/place twins use `warnOnce` with entity-keyed sites (:3482, :3493, :4511, :4528).
- **Mechanism:** a persistently-faulting `touchAuthoredExactTarget`/swap observer warns once per authored admission — bounded by commit rate not frame rate, but it breaks the dedup contract the same code applies elsewhere and warn-storms during upgrade bursts.
- **Fix sketch:** `dedupWarn`/`warnOnce` with static site keys (entity id in args, not the key — the encounterDirector precedent from wave-116 P1).
- **Effort S · impact L-M · risk: trivial.**

### F6 (S / L) — `_sectorExitCleanupIter` catch swallows silently

- **Evidence:** `src/render/renderer.js:3195-3200` — the W118 paced sector-exit drain's `catch (_)` clears the iterator with no `noteLaneFault` and no warn.
- **Mechanism:** a faulting cleanup iterator dies invisibly on its first throw — every other paced lane stamps the lane-fault rollup (that's the telemetry this lane's audits read). Observability only.
- **Fix sketch:** `noteLaneFault(owner.state, 'sectorExitCleanup')` + `laneWarn(owner, 'sectorExitCleanup', '[render] sector exit cleanup failed', err)` before clearing.
- **Effort S · impact L · risk: trivial.**

# M16 — Build your own escape

**Disposition:** OPTIONAL. **Setting:** Existing outlaw transit or arena-derived adventure site. **Player verbs:** tow, place, lure, sling.

This is a proposed authored scene or refinement of an existing one, not a claim the mission is absent. Search current content for the same physical question before adding a new row. Program context: [SFQ-P03](../programs/03-massline.md), [SFQ-P08](../programs/08-missions.md), [SFQ-P11](../programs/11-regions.md).

## Existing runtime integration

Candidate route: **authored_set_piece**. The current mission catalog and world-site owners decide exact type/params and real event/API names. Description strings in older mission data are not executable contracts. Do not create a new mission engine for this brief. [S16, S17]

## Discover and commit

A risky pickup gives advance notice of the likely pursuit and leaves preparation time.

Expose actual equipment, cargo, permission and capacity prerequisites before charging money or moving cargo. Required tools need a legitimate acquisition/service route. Preserve a decline/abort and a recovery path.

## Physical layout

An escape route lacks a useful anchor but contains a movable heavy wreck. The player may reposition it before taking the dangerous cargo.

Measure actual reference hull/workpiece sizes, mass, cruise/earned speed, turn radius and camera depth before choosing final coordinates. Use [play-space guidance](../engineering/04_PLAYSPACE_AND_BALANCE.md); no coordinates in this brief silently override the current level.

## Playable phases

Scout route; reposition an anchor or clear cover; take the cargo; choose a sling or gunfight exit; deliver or dump pursuit bait.

## At least two approaches

Prepare geometry and escape on a Massline tangent; skip preparation and use conventional cover/fighting with higher pressure.

## Failure and aftermath

An anchor lost during setup is not magically replaced; a quieter alternate exit remains possible.

## Reward and progression

A preparation-sensitive contract payout, no bonus for an exact stunt animation.

## State and UI

Prepared object pose, cargo custody, pursuit trigger and escape settlement.

Use current ORRERY/mission/comms surfaces for objective, denial reason and result. Track real object identity and current position; no marker-only success. Transaction and actor/cargo conversion must settle once.

## Acceptance tests

Move anchor too far; fail prep; bring different hull; reload after preparation; enemies displace anchor.

Run both ordinary approaches and one plausible unplanned manipulation. Test at the real camera with sound, plus relevant pause/rebase/save and device cases. The scene is complete only when acquisition → action → consequence → reward → return works without debug grants. See [mission workflow](../workflows/05_MISSION_PRODUCTION.md).

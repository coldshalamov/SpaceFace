# SFQ-P15 — Ancient machines that perform consequential work

Verge-Layer machines are surviving institutions whose procedures visibly move, preserve and transform the world.

**Disposition:** supporting source program, not an independently active queue. **Milestone band:** 4. **Existing owners to search:** AE machine lane / PR 170; deepen existing kinds before adding kinds.

## Baseline and uncertainty

At the pinned PR, machines are spawned collides:false/physicsBody:false and have authored procedure/movement loops. A courier proximity path grants inventory directly; a Mason orbit/beat is not proof of construction. This proposal makes selected workpieces physical without requiring every machine to be a combatant.

4. RANKED FIXES (one owed; everything else is an observation)
   F1. arcRail.js pointAt() early return strands the Hand after free-tracking.
     Where: Hand bead ~(196,646) while NEW GAME hovered/awake (rehov shot).
     Wrong in one sentence: pointAt returns early when index === handIndex, but
     free-tracking moves the spring without changing handIndex, so re-hovering
     (or re-focusing) the indexed verb never returns the needle to its stop.
     Fix: return early only when the needle is already AT the stop, e.g.
       if (index === handIndex && !instant) {
         let d = Math.abs(handSpring.value - geo.angles[index]) % 360;
         if (Math.min(d, 360 - d) < 0.5) return;
       }
     Check: rehov repro — hover NEW GAME, park (150,750), re-hover NEW GAME —
     bead must return to (663, 244.6). Self-heals today via any other verb or
     pointer-leave, which is why this is owed rather than blocking.

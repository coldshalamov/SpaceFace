# Overlap map — candidate sources are not independent write sets

The bank is broad; the engine is shared. Domain separation is for understanding, not an automatic parallel-execution guarantee. Inspect current exact paths before every batch.

| Shared seam | Likely colliding domains | Integration rule |
|---|---|---|
| `src/systems/input.js`, V3 intent and action edges | hand, interface, continuity, performance | One integrator for the selected input contract; preserve raw axes and discrete-edge semantics |
| `src/systems/traffic.js`, job materialization, cargoCustody | jobs, industry, economy, missions, continuity, slices | Resolve a real lot's origin/transfer/sink once; do not have each packet add its own shipment state |
| `src/systems/missions.js`, encounterScripts, law | missions, consequences, discovery, slices | Keep the current mission and lawful owners; share a stable result/receipt rather than parallel resolvers |
| `src/render/renderer.js`, readiness, residency, publisher | picture, VFX, performance, continuity | Serialize publication/lifetime changes; compare variants and generations before unrelated visual work lands |
| `src/render/vfx.js`, presentationOrchestrator, cues | hand, ordnance, VFX, audio, picture | One canonical event/phase per physical cause; consumers must not settle gameplay |
| `src/save/saveSystem.js`, migrations, stable IDs | continuity and every durable feature | Minimize saved state; one migration/commit integration pass for the selected batch |
| `src/ui/station/screens/*`, ORRERY primitives | interface, economy, builds, missions | Task-required functional edits only, consistent with current ORRERY direction and active foreign hunks |
| Forge manifests, body/collider geometry | picture, industry, performance | Verify the real source→export→runtime chain and preserve physical topology; source ZIP omissions are not missing assets |

## Suggested parallel pattern

One worker can address a bounded civilian-job issue while another handles an unrelated input edge and another edits a domain-isolated audio recipe, provided their actual current write sets do not intersect. A stronger integrator then checks the common player route. Do not parallelize three speculative renderer fixes or three migrations simply because their plan IDs differ.

## Dependencies are capabilities

A packet's prerequisite refers to a needed capability, not a demand to implement another packet literally. An existing correct system satisfies it. Conditional links in the bank are intentionally sparse. Integration packets reuse completed outcomes and must not count the same underlying implementation twice. No task requires completing all lower IDs.

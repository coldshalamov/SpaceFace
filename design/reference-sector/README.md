## Purpose

This package replaces the earlier broad “Reference Sector Integration / Value-Harvest” prompt with a repo-grounded production program.

The earlier low-interference prompts successfully produced several useful source-only libraries:

- an occupational NPC craft donor pack;
- an Everyday Space industrial-prop donor kit;
- a 58-entry ambient microevent library;
- existing current graphics/VFX plans and remaster lanes;
- existing Ceres activity-pocket data, traffic actors, route acceptance and performance evidence.

However, the repository review shows that these outputs are not equally mature and should not be bulk imported. The NPC and prop packs are explicitly retained as **design-candidate donors requiring re-authoring**. The microevent library is data-only and its proposed universal runner would be premature if integrated wholesale. The current Physics-as-Spectacle program already owns the VFX/physics presentation direction. Ceres itself already has four authored pockets, nine stable activity identities, a public-route five-minute gate, and a current dependency position in the recovery program.

The correct next large chunk is therefore:

> Build Ceres as the production benchmark for the game: one normal-route, ten-minute lived-world slice that proves authored composition, visible systemic activity, player interference, physics spectacle, art direction, performance and a repeatable production method.

The work should **select, re-author, promote and compose** only the strongest assets needed by that slice. It should not create another universal framework or another warehouse of future content.

## Honesty gaps

- **The cut is not a flown chase.** The doctrine runtime advances on its own clock from a fixture
  perception; the harness then publishes the phase it produced on the same bus event the live AI
  uses. That is one step short of a piloted encounter, and no headed capture exists.
- **Ace cut is wired but unscened.** `isNamedAceEntity → ace_cut` at range 220 on eight authored
  offensive phases. The scenario pins only the specialist `attach_window` cut. A named ace that also
  carries `tether_control_raider` takes the specialist path first.
- **"Carries a line-cutter" is a doctrine verb, not hardware.** `verb: 'cut_line'` on
  `tether_control_raider` (range 180) in `src/ai/specialistPlans.js`. There is no fitted cutter
  module — audited 2026-09-09, `MODULES` contains zero entries whose id or name matches `/cut/i`,
  and the test pins the narrow absence of a `line_cutter` / `cut_line` module id so a later cutter
  makes this receipt line go red instead of going quietly stale. The `line_cutter` string elsewhere
  in the tree is a *player* loadout preset label for the `monofilament_sweep` head
  (`src/ui/ship/loadoutPresets.js:15,33`), not NPC hardware.
- **The ignore is an admission gate, not a struggle.** `validateTwinBridlePair` returns
  `heavy_endpoint_resists` before `attachments.create`, so the heavy refuses the rope rather than
  wearing it and shrugging it off. The player keeps endpoint A and the setup stays live.
- Hitch cannot fit the M head: S utility vs `mod_twin_bridle_m`. Pinned by the sibling head test.
  This leaf did not retune fittings.
- This leaf did not retune 031.00 / 031.01.

## Status: INTEGRATED

Flying out of Tethys mid-recovery now parks the Third Shift run instead of
killing it. The contract stays active, pays nothing, and decides nothing at
the boundary; flying back re-embodies the same body — same schedule, same
stable identity, same position, velocity, spin, hull, and capture approach —
where the run left it. No new top-level save key: the body snapshot rides the
already-serialized mission record, and `state.heistFacilities` stays out of
the capture plan exactly as the brief's stop rule demands.

## Implementation notes

- `heistMissionRuntime._suspendRun` fires inside `onSectorExit` for a launched,
  undecided Third Shift record. The snapshot reads the raw entity map entry:
  the facility's own `sector:exit` listener registers first (registry order
  423 < 449) and marks the body `alive=false` before the runtime sees the
  event — `liveEntity` would already say it is gone. The `.06` drive-tracked
  `capsuleLastPos/Vel/Mass` are the same body truth if the entry was removed
  `immediate` or the exit raced a kill.
- Resume routes through `drive()`, not a `sector:enter` listener: the same
  path covers re-entry AND a reload into the sector, where no enter event
  ever fires. A suspended record out-of-sector returns early every tick —
  every clock (run window, unlaunched deadline, arbiter step) is frozen.
- The window is preserved by shifting `launchTick` forward across the
  suspended stretch; `sectorExitedAtTick` is cleared on resume so a later
  destruction classifies honestly.
- `heistFacilities.respawnSuspendedCapsule` mirrors the launch spec field for
  field, minus the arc/cue/event semantics of a fresh launch. It restores
  `data.breakawayCapture` from the snapshot and relinks `owned.capture` when
  the schedule survived — after a reload the ordinary `adoptRestoredLoad`
  path adopts the respawned body by stable identity and rebuilds the schedule
  itself. Both resume routes converge on the same custody identity.
- A respawn refusal leaves the record suspended rather than fabricating an
  absence — fail-closed, diagnosable, no invented outcome.

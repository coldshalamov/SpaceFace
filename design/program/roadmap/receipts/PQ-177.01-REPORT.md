### The clause that is not live — fresh/stale

The inspector reads the docked station and nothing else (`src/ui/station/screens/market.js:57`).
The market screen's `onShow` emits `economy:marketOpened` (`market.js:722`). The economy answers
that event with `snapshotIntel(sid)` (`src/systems/economy.js:744-747`), and `snapshotIntel` calls
`recordMarketMemory`, which writes `seenAt: state.simTime` (`economy.js:1217`). The economy update
then re-stamps the docked station on **every** tick, by design —
*"The docked exchange is a live feed"* (`economy.js:876-879`).

So by the time `quoteAgeWord` runs, the memory it reads was written by the same screen-open that is
about to render it. `AGE_BAND_FRESH_S` is 600 s (`src/ui/marketIntelligence.js:23`); the measured age
is 0 s.

Measured, docked, live event order:

    simTime 2000  ->  seenAt 2000  ->  age 0 s  ->  ageBandFor().key = 'fresh'

The test's stale case (`a remembered quote older than the leftover fresh band reads stale`) reaches
`stale` only because `bootCeres` hand-writes `mem.seenAt = memorySeenAt` (0) **after** calling
`recordMarketMemory` at `simTime = 2000`. That is a constructed input: the live route overwrites that
exact field one event earlier. PQ-140.01 shape — a green test feeding the law a number the live route
cannot produce.

Follow-up 2026-09-09 retired the word on the docked inspector. `quoteAgeWord` now returns empty.

### True caveats the receipt should carry

1. **The cone is not a cone.** `predictPriceCurve` returns one deterministic mid per step — there is
   no spread. The "band" is that single line skirted down to the chart floor. At Ceres the entire
   115 s forecast spans **36–38 cr**: a 2-credit ribbon hanging off a 41-point history. It reads as a
   shaded tail, not as uncertainty. The done-when asked for a "band" and got one; a reader who hears
   "cone" will expect width that is not there.
2. **The forecast freezes stock.** `stockMid` is computed once from the current `entry.stock`, and
   only the cycle's time factor advances. The live tick drifts stock toward equilibrium every update,
   and any trade moves it. The painted future is "price if nobody trades and drift stops".
3. **"Last ten minutes" can be backfill.** `seedPriceHistory` writes all 64 points by evaluating the
   cycle *backwards* from the seed-time stock. At a market's first ensure the whole ten-minute window
   is modelled; it becomes lived-through only as ticks accrue (15 s per sample, so ~10 min of
   populated time). The label claims observation the data does not always carry.
4. **"stale" collapses two bands.** `ageBandFor` has three keys (`fresh` / `mid` / `old`); the
   inspector folds `mid` and `old` into one word, so its vocabulary is narrower than the rest of the
   intel layer. Moot while the word is pinned to `fresh`.
5. **The test does not drive the live render.** It calls `marketQuoteHtml` directly and re-implements
   the window (`lastTenMinutes`), the regime word and the age word locally. The production
   `windowHistory`, `priceHistorySeries` and `quoteAgeWord` are never executed; the live call-site is
   covered only by source-text regex in the fourth test. The parallel implementations agree today on
   seeded history, which is why the window assertion passes.
6. **The sale line is verified at qty 1 only**, where `round(sell) × qty` and `round(sell × qty)`
   coincide. `saleLineHtml` also clamps qty to ≥ 1, so a 0-quantity stepper still prints a one-unit
   sale, and the line shows station pay even on the Buy tab.
7. **A 177.02 claim shipped in this commit.** `presentSupplyChain` replaced
   *"This dock does not buy it."* with *"This dock buys it."* for `dockRole='neither'`. Whether the
   new sentence is true at every berth is a 177.02 question; this test only asserts that the chain
   markup survives, so nothing here stands behind it.

## Hypothesis (one)

When a well is dropped, `src/systems/fields.js` only queried colliders, so cargo with `collides:false` never entered the candidate set; scavengers never registered a cone because only player input and spawn-time `fieldAnchor` created fields. Unioning pickups/wrecks/payloads into the candidate set, and letting scavenger-doctrine NPCs attach a cone when loose mass is nearby, should move bodies-bent from 3 colliders to ≥ 5 mixed bodies and prove one NPC role deploys a field.

# PQ-137.08 — Drawn flight cuts corners tangentially

Integrated in `09d0bce3`, from Cursor Grok recovery ending at `95b354c9`.

The follower constructs a pilot path with a turn-radius corridor and a backward speed profile. Clustered corners no longer create overlapping fillets, reverse progress or tangent jumps. The strict five-degree tangent test remains intact.

On the production scenario at seed 4242, corner/S/hook strokes respectively average 82.88%/123.78%/117.93% of cruise. Slowest speeds are 65.98%/66.92%/70.17%; maximum departures are 0.2974/0.0420/0.0564 turn radii, with complete ordered coverage. All 28 integrated draw-to-fly tests pass.

## THE FRAMES

**The premise that there is no drawn stroke on the Crucible route is wrong, and this lane proved it
on the live game rather than arguing it.** Draw-to-fly is an ordinary flight mode, not an
adventure-route feature: `KeyG` is bound to `autoFire` in all three control schemes
(`src/systems/input.js:282`, `:302`, `:320`), `toggleAutoTarget` (`src/combat/autoTargetMode.js:36`)
flips `state.input.autoFire` with no item, tech or route test, and while it is on the pointer handler
feeds every `mousemove`'s `movementX/Y` to `recordAutoTargetPath` (`src/systems/input.js:769–779`),
which turns the pen's screen track into a world-space route the follower flies.

**Probe, real Crucible route, 2026-09-05** (title → door → `physics_toolkit` → seed 4242 → "Hold the
line", then keyboard and mouse only, no state writes):

| Step | Read back out of `window.SF.state` |
|---|---|
| before `KeyG` | `autoFire: false`, player speed **0.37 WU/s** |
| after `KeyG` | `autoFire: true`, pointer lock taken on `#gl-canvas`, route `active: true`, 2 points |
| after 22 dispatched moves | **24 route points**, `drawing: true`, `pointIndex: 6`, speed **67.1 WU/s** with **no throttle key held** |
| 4 s later | `pointIndex` **6 → 12**, speed 45.1 WU/s, still `mode: 'flight'`, hull moved ~78 WU |

So the ship draws and then flies what it was given, on the default route, through the real input
path. A strip tape can therefore drive B8, and one now does: **`draw_stroke` has been added to
`STRIP_SCENARIOS`** in `scripts/lib/bench/frameStripCapture.mjs` — a straight leg, one hard 90° corner
and a second straight leg (the corner case B8's numbers are written about), with the first pointer
move spent *before* the mode is switched on, because the virtual pen integrates deltas from wherever
the real cursor was and an uneaten first jump pins it to the edge margin. `node --test
test/frame-strip.test.mjs` is 21/21 green with it in place.

**What the capture attempt gave, honestly: nothing — there is no `draw_stroke` manifest.** The one
run made of it reached flight, cleared the HUD, waited 141.6 s for the renderer to admit the hulls
(113 px hull, 1482 lit pixels on it, four hostiles drawing), and was then **refused by the harness's
own settle gate**, which requires three consecutive two-second windows at or above 0.60 of real time
and saw 2–89 % bouncing for the full 60 s it is allowed. `captureFrameStrip` throws rather than
photograph a game that is not running at speed, which is correct, so no frames and no manifest were
written. That is the machine: three other lanes were running headed browsers on this box and the CPU
sampled 76–100 % all session; across nine strip runs the game read 0.399–0.582 of real time *with
nothing encoding at all*. **No strip of a drawn stroke exists yet, at any speed**, and nothing about
the stroke's speed profile could be read off a slow one anyway (`CANONICAL_BUILD_MAP.md` §1.3 law 2):
the 82.88 % / 123.78 % / 117.93 % of cruise in the paragraph above remain the headless bench's
numbers.

**What is still missing, exactly.** Only a quiet machine. The tape, the route, the mode and the
follower are all proven live. Two things would make the eventual strip answer B8 rather than merely
show it, and both are outside the `STRIP_SCENARIOS` block this lane owns: `state.input.autoTargetPath`
(`points`, `pointIndex`, `drawing`) is not sampled into the per-frame manifest record, so a viewer
cannot see from the manifest how far along its own line the ship is; and the cross-track departure the
bench measures in turn radii has no per-frame equivalent, so "cuts corners tangentially" cannot yet be
read off the pictures.

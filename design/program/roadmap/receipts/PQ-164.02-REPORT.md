## What changed

- Trackpad gestures write the existing Massline key seams (Space latch, W/S reel, Y throw, Shift boost, draw-to-fly stroke).
- Deck size and default UI scale are a shipped pin: 1280×800 at scale 1, no sideways overflow, Steam Deck sentence visible.
- Settings Controls uses one shared Deck header/note so the still and the test cannot drift.
- Capture walks that sheet in Chromium without booting the 3D picture.
- UI input consumes latched trackpad wheel and pointer in flight so pinch/scroll do not fight camera zoom.

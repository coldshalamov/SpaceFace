## Notes

- The palette mounts inside `#screens` deliberately: entityLinks' delegated handler and drawer
  host lookup both live there, so result rows open the same drawer as every other tagged mention.
  In flight the palette itself is the `.screen` host — the drawer mounts inside it.
- `/` on the galaxy chart still focuses the chart's own search — that field is the in-context
  find for map marks (jump gates, claims, rumours the dossier does not cover), and its hint text
  stays truthful. Global find remains one key everywhere else, and `M` then `/` reaches it from
  the chart.
- Note keys are stable ids (sector/station/data id), so a note survives reloads; a mark without a
  stable id shows the verb disabled with a reason rather than a control that silently does nothing.
- `check:baseline` and `check:visual-regression` were run for the packet; on this host the
  browser-capture cells are contention-limited, and nothing in the diff touches the sim hash —
  find and notes are UI-owned state plus a resolver read path.

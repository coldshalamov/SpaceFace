## Status: DONE — readback percentage produced: 100% fact attribution, with flagged text seams

The packet required two things: the packet test re-run live, and a blind readback percentage
that is measured rather than invented.

**Packet test:** `node --test test/pq-150-01-mechanic.test.mjs` — 7/7 passing on HEAD.

**Blind readback method.** A corpus generator (`.probe-tmp/pq207-03-corpus.mjs`) calls the real
`leftoverMechanicLine(state)` against twelve hull states covering every emitted line family:
each scar band on its own (graze/hard/heavy/crushing), a patched scar, a clean hull, wanted
heat, a filed ledger fact, a New Run+ legacy carry, a dock spill, and two composite hulls.
A blind read-only subagent received the twelve card texts verbatim — no source access, no
answer key — and attributed each card's factual claims (damage class, hull location, repair,
legal, ledger, legacy, cargo).

**Measured result:**

| Measure | Result |
|---|---|
| Cards with all ground-truth facts correctly read | 12/12 (100%) |
| Scar class + facing correctly attributed | 8/8 scar-bearing cards (100%) |
| False attributions (claims not in ground truth) | 0 |
| Distinct claims read | ~35/35 |

**Flagged text seams (reviewer observations, not attribution failures):**

- `legacy` card: `"... the Ashfall ending. the Moth is still out there."` — the ace clause joins
  lowercase mid-sentence; concatenation artifact visible to a first-time reader.
- Composite hulls print a second `Tessera:` header mid-card — the stitched line structure leaks.
- `"Clean plate. Nothing on this hull to file."` followed by `"the law already filed the rap"`
  reads as a surface self-contradiction on fast first read.
- `"The ship ledger already has a fact on this hull"` — `a fact` is deliberately vague;
  the reviewer could not say what kind of fact (the line is presence-only by design, PQ-207.00).
- Idioms carry real ambiguity a cold reader hits: `"the frame kept it"`, `"the paint still
  argues"`, `"do not call it weather"`.

None of the seams changed factual attribution: every card's ground-truth content was recovered
by the blind reader. The readback lands — the mechanic's lines communicate the hull's true
state; the residual defects are clause-stitching polish, filed as D78 in the demo defect ledger.

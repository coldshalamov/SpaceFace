   UP past its status owner via `flashMinLife`, breaking the never-outlive invariant. Fixed with
   a `_spawnFlashAccessibilityBypass` raised only around the status-attached spawn loop; the
   plan's own flash/motion handling is the single accessibility application.
2. Reconcile fallback untested — new test: a field loop whose `bombs:fieldEnded` never fires is
   swept by `syncBombAudioLoops` once the bomb leaves the field phase; same backstop proven for
   an expired status loop. Suite 22→24.
3. `game:newGame` alias not subscribed — added alongside `game:new`.
4. Per-poll allocations in the 50 ms/60 Hz collectors — noted, not fixed (bounded, small; the
   field/status `wanted` scratch arrays ARE reused; `ranked` + the reconcile Set allocate). Left
   to the presentation-allocator campaign.
5. Continuous status cue ids mapped but not intercepted in `_onCue` — a stray
   `audio:cue {id:'combat.status.burning'}` would have spawned an untracked continuous voice.
   Fixed: `isBombStatusLoopCue` interception routes them to `syncBombAudioLoops` and returns.

# PQ-160.01 — Auto-clip (receipt)

DONE PQ-160.01 — A bolas kill marks an exportable clip window at seed 16001. Pause → Clips lists
it. Export writes a real GIF (or MP4 container) when frames exist, rasterizes a software title
card when they do not, and fails closed with `gpu-export-unavailable` for a bare id. Electron
saves through the packaged host; the browser downloads the file. The live bus now feeds the
director, including production `entity:killed` receipts that carry no tick.

WHAT I FOUND — The repo already had the authoritative stunt detector (`src/combat/stuntTaxonomy.js`,
fed by `stuntGrammar`'s `stunt:trickDetected` bus event) and the PQ-160.00 replay ring, but nothing
watched a rated moment, nothing marked a window, and no surface listed or exported a clip. The
first pass of this leaf left the director off the production bus, so Pause → Clips would have
stayed empty on the default route.

WHAT I CHANGED — Added a pure clip director that turns trick/kill receipts into bounded clip
windows, a bus subscription that stamps seed and tick onto live receipts, a Clips surface on
pause (list + Export GIF/MP4), a GIF89a encoder and a raw-RGB ISO-BMFF MP4 muxer, an Electron
`spaceface:save-clip` save dialog, and a browser `<a download>` hook. Boot calls
`installLiveClipDirector` so a bolas kill on the live bus lands in the list.

WHAT YOU WILL FEEL — Land a named stunt or a kill, open Pause → Clips, and the moment is in the
list with its name, rarity, tick, and span. Export GIF/MP4 writes a file. In the packaged app it
opens a Save dialog; in the browser it downloads. Without a captured window or a marked clip it
says export is unavailable rather than inventing a file.

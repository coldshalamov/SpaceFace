and legacy screens were almost entirely untagged. The sweep covered every file in the packet's
write set (`src/ui/entityResolver.js`, `src/ui/whyReveal.js`, `src/ui/hud.js`, `src/ui/galaxyMap.js`,

## What landed

**Resolver (`src/ui/entityResolver.js`)** — contract dossiers now also read
`state.missions.boards[*].slots`, the live station mission-board pool, with the board field
spelling (`reward_cr`/`rewardCr`, `destSectorId`, `brief`/`summary`) and an "On offer" status.
Board offers carry their own `title` as the dossier label via the existing `body.label` fallback.

covers `WEAPONS` and `BODY_MODULES` (claimable-body installations) alongside `MODULES`, so every
`module:` emitter — shipworks chooser, tech-tree unlocks — produces a door that opens; dossier
kickers read Weapon / Module / Installation and tolerate the installation field shape
(`cost`/`slots`/`desc`).

## Review iteration (independent read-only agent, adversarial)

Eight findings, all addressed before close:

1. **Drill settle modal trapped Tab on "Acknowledge"** — the new ore links were focusable but
   unreachable. The trap now cycles `button, [data-entity]` forward/back through the modal.
2. **Bar contact `captain:` tag could never resolve** (contacts are `contact_*`, not aces) — the
   tag was cut; the name renders as plain text. Dead tagging removed rather than shipped.
3. **`module:wpn_*` refs emitted but never resolved** — the module index now covers `WEAPONS`, so
   shipworks weapon rows and the five weapon tech-unlock rows are real doors.
4. **Check proved helpers called, not ids resolvable** — new E2 crawl walks every emitter-facing
   id space (tech unlocks, fittable catalogue, ores, fabricator/outpost goods); it immediately
   caught `module:mod_sensor_post`, a claimable-body installation emitted by tech unlocks, and the
   index now covers `BODY_MODULES` too.
5. `contract:null` trap on the bar board — guarded to plain text.
6. Shipworks chooser rows are two Tab stops (row preview + dossier door) — accepted as designed;
   Enter on the link opens the dossier, click/row previews.
7. Contract refs on live records can stale between render and click — a known shallow window;
   the drawer fails closed and emitters repaint on state events. Documented, not a live bug.
8. `prettyId` label passed unescaped — now `escapeHtml`d; crucible blurb links only the hull
   name, not the whole sentence.

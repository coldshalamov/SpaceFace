## What changed

- `src/systems/gamepad.js`: `GAMEPAD_DEFAULT_BINDINGS` (the former fixed `ACTION_MAP`, now
  exported and frozen), `GAMEPAD_BUTTON_LABELS` (std button -> player glyph),
  `gamepadShareAllowed` / `findGamepadBindConflict` (context classes: flight, modal-only, both;
  the designed accept+massline arbitration is the one explicit share), and
  `resolveGamepadBindings` — untouched actions keep shipped defaults first, overrides then claim
  buttons in canonical order, and an override that loses every claim to a disallowed share falls
  back to the default so a corrupt profile can never leave the pad worse than stock. The tick
  resolves the map behind a reference-identity cache (zero per-tick allocation on the stock
  path), records raw button edges into a bounded `drainButtonPresses()` queue, and honors
  `captureMode` by reporting every action inert while still feeding the capture queue. PQ-164.03
  haptics are untouched.
- `src/ui/bindings.js`: last-used-device state (`setPromptDevice`/`getPromptDevice`), the resolved
  pad map feed (`setGamepadPromptBindings`), the one-at-a-time capture handler registry, and a
  device-aware `promptLabel(action, device?)` — pad chips resolve through the live map so a remap
  re-labels prompts; verbs with no pad route fall back to the keyboard label rather than print a
  pad lie; touch chips name the overlay buttons.
- `src/ui/input.js`: last-used device arbitration — pad/touch `lastActiveSeq` edges (the shared
  deterministic input sequence, never wall time) versus keyboard/pointer/wheel events, with
  `pointerType === 'touch'` sorted to the touch class. Device flips re-emit the UI-owned
  `dock:range` fact so a live dock prompt repaints under the new glyph. While a capture handler
  is registered, pad presses route to it and nothing else (nav state cleared, `captureMode` set).
- `src/ui/screens/settings.js`: a "Gamepad Buttons" section under Controls — one capture row per
  pad action showing the live glyph, `In use:` denial on same-context conflicts, Esc cancels,
  Backspace restores the action default, a 30 s timeout and click-away so a pad-only player is
  never trapped, and a "Reset pad layout" word. Overrides store sparse at
  `controls.gamepad.bindings`, which the existing settings profile snapshot already persists
  (boot restore and old-save merge verified in the focused test).

## Outcome

A player opens **Crucible** from the main menu, picks a hull and loadout (or a starter package), and is
dropped into one authored arena for a scored thirty-wave **Survival** run. Every ten waves a refit; every
level a three-choice draft that changes what their weapons *are* — bank, chain, split, orbit, freeze, burn,
gravity — never a stat slider. The room (moving shutters, reflective plates, gravity pylons, currents,
thermal zones, conductive relays) participates in every kill. The player can explain every link of a
chain-kill. **Combat Lab** lets a player or agent launch any build, any enemy package, any seed, and
replay it exactly. Adventure is untouched by any of it; what proves fun migrates into Adventure later as
fitted, earned, consequential tools.

The route is the ordinary game path: New Game → Crucible → run → results → restart same seed. No second
registry, no alternate physics, no Lab-only code path.

## Binding rulings (from §27, restated)

1. `state.mode === 'flight'` stays. Survival is `state.run = { kind:'survival', … }`, orthogonal.
2. Fresh ephemeral state through the real New Game path. Never mutate the live Adventure save, never share
   campaign credits, never share inventory by reference, never write run modifiers into persistent fittings.
   Appendix A.8 campaign-contamination test is a required check from `.02` onward.
3. Explicit validated phases: `inactive → loadout → arena_intro → wave_intro → active → cleanup → draft →
   … → refit → … → victory | ended`. No phase inference from entity counts.
4. `planWave(...)` is pure. Materialization goes through `spawnBudget` + the canonical materializer.
   `DEFAULT_MAX`/`HARD_MAX` are re-audited, not bypassed.
5. `AttackSpec` is immutable with a stable digest; lineage carries root/descendant/generation/visited
   targets and a shared proc budget; §9.7 containment invariants are tests.
6. Consumers only of Physics-as-Spectacle receipts. Never close its gates from here.
7. One game path across Browser, Electron, Sandbox, Crucible, Lab.

or observer framework. Extract a shared abstraction only after an independent gameplay consumer or
a repeated production failure proves the second use.

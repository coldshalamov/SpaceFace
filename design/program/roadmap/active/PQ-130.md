## Outcome

The player is **inside this asteroid**. A stranger glances and sees rock, a hole,
a vehicle, ore as ore, gas as danger — not a sci-fi website with a Minecraft
inset. The HUD is currently ugly *and* too big; leftover chrome is the small warm
object set in the design law's §6, not a shorter copy of the three-bay console.
Cells of this rock read as its stone. The rover is a vehicle you find in a second
and seat **one cell** at a time. Hover confirms with a picture.

**Revision 3 (2026-08-20 owner design session):** the packet now builds toward a
positive design —
[`design/ASTEROID_WORKS_DESIGN_LAW.md`](../../../ASTEROID_WORKS_DESIGN_LAW.md).
Settled rulings: **perfect axis-aligned flat grid** (chess board; zero tilt);
**fog of war removed** (every cell's material visible from the first frame; no
"unsurveyed" appearance; the survey reveal loop gates nothing); **ground-up UI
reboot** (owner: the current chrome is "gray, bleak, and vibe-coded, harsh
fonts" — the gunmetal/tracked-caps console voice is deleted and replaced by the
law's warm palette, vendored Instrument Sans / Spline Sans Mono / Bricolage type,
sentence case, soft shapes); **events happen on the board, never as a permanent
text log**; **≤ 15 visible words** in the default drive view. A polished copy of
the old console fails review even if every checkbox is green.

A vanilla collapse (shorter CSS bays, zoom-only camera, tan×0.7, bigger
sparkles, slower cooldown, truncated inspector strings) **does not close a
leaf.** Read campaign §0 and §3 before editing.

The 2026-08-20 playtest is the defect list; this packet does not invent new
industry mechanics.

Ordinary `--next` still returns fleet remaster. Take
`node scripts/program-dispatch.mjs --id PQ-130` and the first claimable leaf.

## Player route and state machine

1. Flight → Massline tether on an asteroid → Asteroid Works (`drill` screen).
2. Default mode is DRIVE. The STAGE shows a local window of **this** rock around
   the rover. BUILD remains the command-card mode switch.
3. Tap a direction: if the face is empty, the avatar commits exactly one cell and
   stops. If the face is rock, a bore bite starts (visible crack / sink).
4. Hold past the delay: cruise or continue the bore. Release stops the chain.
5. *(Amended rev 3 — fog removed.)* Every cell's material is visible from the
   first frame; survey pulse gates nothing (keep it as a cosmetic assay ping or
   delete it in `.04`).
6. Retract ESC is unchanged. Saves stay the existing drill/site writers.
7. Failure class is “cannot see or steer the board,” not a missing Wave-1 mechanic.

## Player route and state machine

1. Flight → Massline tether on an asteroid → Asteroid Works (`drill` screen).
2. Default mode is DRIVE. The STAGE shows a local window of **this** rock around
   the rover. BUILD remains the command-card mode switch.
3. Tap a direction: if the face is empty, the avatar commits exactly one cell and
   stops. If the face is rock, a bore bite starts (visible crack / sink).
4. Hold past the delay: cruise or continue the bore. Release stops the chain.
5. Survey pulse still reveals veins/gas; the **picture** changes, not only the
   inspector title.
6. Retract ESC is unchanged. Saves stay the existing drill/site writers.
7. Failure class is “cannot see or steer the board,” not a missing Wave-1 mechanic.

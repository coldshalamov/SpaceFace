## Outcome

SpaceFace's interface is rebuilt to an A-list standard by production, not styling: rendered style
frames first, produced assets second (transparent-PNG kits, an SVG icon family and marks, 3D sets
and hull renders), code that assembles those assets to match the frames third, and a
picture-comparison review at every step. The direction is **Field Hardware** — manufactured,
backlit, hand-worn equipment laid over a lit living world, in three registers (POSTER, BENCH,
EDGE). The title goes live first as the owner's veto point; every surface follows on its own
packet; the sweep and a blind comparison close the program.

## Why (the finding)

Ten passes since July converged on text in bordered boxes on a black ground because every pass
was CSS written in one session against a prose target, with no produced assets, judged against
docs the previous agent wrote. The code audit of 2026-09-10 added the engineering half: no screen
has a lit world behind it by design (any screen stack freezes rendering; the only 3D under a menu is
a second WebGL context refused on Intel GPUs), so "the world is the interface" never had machinery.

## Floors that no leaf may trade away

12 px type (incl. canvas), WCAG AA contrast, reduced-motion and flash-reduce, forced-colours,
keyboard/pad reachability with a visible focus ring, labelled icon-only controls, no idle rAF,
≤ 2 ms UI frame and ≤ 1,500 DOM nodes per surface, no `backdrop-filter` in flight, colour literals
as tokens, the simulation and determinism goldens untouched.

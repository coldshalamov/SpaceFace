## Outcome

SpaceFace follows one explicit Browser/Electron lifecycle state machine: foreground-visible, foreground-occluded, hidden-or-minimized, system-suspended, and restoring. ## Lab and broker gap

The current lab cannot drive native window minimize, OS suspend, lock/unlock, Chromium throttling, audio, or GPU submission. Keep deterministic foreground tape comparison at L2. Add a broker-managed `performance-lifecycle` manifest with separate Browser visibility and Electron native lifecycle cells; direct candidate probes remain diagnostic until the manifest owns the claim.

The exact claimed harness uses paired tracked manifests because each broker claim owns one runtime.
The Browser cell drives real Chromium page visibility and observes the production loop. The Electron
cell drives the actual isolated `BrowserWindow` through Playwright's main-process bridge for
blur/minimize/hide/show/restore; those are shell controls, not renderer mutation. Both cells must prove
zero hidden loop/submission deltas, a single zero-delta restore frame, released input, audio recovery,
foreground-equivalent digest/cadence, repeated-transition stability, real GPU identity, and complete
owned cleanup. OS suspend and workstation lock are not synthesized through EventEmitter calls; if a
safe native host transition is unavailable, that exact physical subclaim stays named and open rather
than contaminating the machine-actionable BrowserWindow result.

## Outcome

Every flyable player and NPC ship **except Hitch/Kestrel** looks like a manufactured 2026
A-list craft, honestly better than the live Hitch body. One leaf is one ship: polish that
ship until Hitch no longer wins, wire only that ship, then the next leaf. An overnight or
“non-INFERENCE work in the build map” goal **keeps going** through every remaining leaf;
it does not stop after Hornet. Hitch stays the untouched quality floor. No ship self-promotes
to accepted.

## Why one ship per leaf

Do not run a stage across the whole fleet (promote everyone, then rebuild everyone, then
review everyone). That ships unfinished work and forgets what the last ship taught.

Finish Hornet. Then Drifter. Then the next name on the list. Shared factory helpers may
improve, but only the claimed ship is rebuilt, judged, and wired in that leaf.

## Work breakdown

### One-ship contract

Every leaf does all of this for **exactly one** ship, then stops.

The technique law is
[`docs/visual-assets/ADVANCED_MODEL_TECHNIQUE_CONTRACT.md`](../../../../docs/visual-assets/ADVANCED_MODEL_TECHNIQUE_CONTRACT.md).
A lofted hull with boxes, a tinted shared texture sheet, a successful factory script, or
an iteration count **does not close the leaf.**

1. Freeze identity. Read Hitch stills and that ship’s refs.
2. Follow the contract session order: form (MTX-01–15) in clay until the clay is not
   primitives, then UVs, then mesh-derived bakes, then surfaces, then LOD/export.
3. Fill `TECHNIQUE_LEDGER.json` for this ship from
   [`TECHNIQUE_LEDGER.template.json`](../../../../docs/visual-assets/TECHNIQUE_LEDGER.template.json).
   Every mandatory MTX row for the ship’s class must be `implemented` with a still crop
   from the **exported** GLB.
4. Required stills: clay three-quarter, material three-quarter, grazing, ORM isolation,
   normal isolation, material ID, plus `bay_interior.png` and `drive_rear.png`.
5. Compare material three-quarter to Hitch. If Hitch still wins, or clay still reads as
   a tube with boxes, the leaf is not done.
6. Wire **only this ship**. Status stays `integration_candidate`.
7. Commit that ship. In a single chat, stop. In an overnight / map-campaign / “do all of it”
   goal, immediately take the next PQ-050 leaf.

Automatic fail (do not wire):

- Factory loft + parented boxes as the shipped hull
- Shared Wasp/other-ship sheet with a MixRGB tint as the only albedo
- `shade_smooth()` on the whole object
- Bay cutter that never leaves the skin, or a liner that fills the hole
- Solid transmissive canopy brick
- Imagen / concept pixels used as normal, AO, or ORM
- Any mandatory MTX row missing, `claimed`, or `blocked`

Wasp extra: hull ≥800 triangles on every LOD, or keep the previous live file.

## Non-goals

- Any Hitch / Kestrel edit or borrowed Hitch identity
- Changing stats, sockets, collision, or roles
- Wiring blocked accessory `pelican.glb` / `wasp.glb`

## Performance and quality budget

LOD0 keeps cavities, frames, vanes, and material boundaries. LOD1 keeps load path and
openings. LOD2 keeps silhouette. Do not pass a cost gate by deleting authored construction
or lowering default quality.

## Verification budget

- `npm run check:baseline` before and after the leaf
- The routing test named on that queue row
- This ship’s stills vs Hitch at the four views
- `check:assets:live` only on a clean tree

- Would Hitch still win in a side-by-side three-quarter?
- Did any other ship or any Hitch file change?
- If this is Wasp, did hull triangles stay at or above 800?

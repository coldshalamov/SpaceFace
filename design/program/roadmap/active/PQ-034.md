## Outcome

SpaceFace gains one versioned baseline/candidate harness that can independently answer four questions: did the game remain semantically equivalent, was the measurement valid, did the selected owner improve outside run noise, and did the candidate remain inside the absolute budget? The ordinary proof route alternates baseline and candidate across the same seeded Browser and Electron scenarios—boot to controllable flight, quiet and dense flight, combat, travel, dock/undock, save/Continue, authored cold/warm admission, lifecycle, and context recovery—while binding every sample to one frame/tick/query identity and exact process/environment evidence.

This packet changes evidence authority, not gameplay. A faster but different game fails equivalence; an equivalent run under a slow no-op control fails measurement validity; a valid equivalent run without a repeatable improvement closes only as neutral evidence.

## Performance and quality budget

- Instrumentation disabled: no per-frame allocation and timing overhead below measurable noise.
- Instrumentation enabled: under 1% median owner/callback overhead on the matched route, with bounded ring/slab storage and explicit overflow diagnostics.
- Every GPU query terminal state preserves its immutable origin identity; a dropped, disjoint, context-lost, nested-refused, or undrained query invalidates the affected timing claim rather than being silently omitted.
- Artifact count and bytes are bounded per predeclared cell; raw traces are ignored evidence, not tracked source. Paired evidence shares `sourceCandidateDigest` but never aliases runtime broker or raw-trace digests.
- Process enumeration occurs at bounded route boundaries, not continuously.
- Scenario entity/population, visuals, settings, viewport, seed/save, and route remain identical between arms.
- Reports publish p50/p95/p99/max, long frames, missed-vsync/multi-step data, phase owners, GPU confidence, uploads, allocation/GC, admission, and process-contamination status where available.

## How agents get this wrong

### Senior implementation direction (2026-09-06)

Keep visible-row rendering, idle sleep and shared owner logic. For `.01`, a 2,000-row fixture must
exercise the production list component, preserve selection by stable identity through sorting and
filtering, and reach the first/last row by keyboard with correct focus and accessible row counts.
For `.02`, measure UI work separately from whole-game frame intervals; an unchanged screen does
not rebuild DOM, while a changed price, target or selection still updates promptly. For `.03`,
remove dead presentation only after its consumers use explicit shared modules. The 300-line target
is a smell detector, not permission to split a monolith mechanically or change station behaviour.

These are the ways a lazy first try fails this packet. Read them, then do the work as if the owner will play it tonight.

- Optimising by removing content or density: the budget is met by structure, never by showing less.
- Deleting legacy modules before the live station stops importing them (the Phase 7 refutation).

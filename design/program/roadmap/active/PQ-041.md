Return `FAIL` on route/semantic divergence, security relaxation, direct/unclaimed evidence reaching M6, missing `app.isPackaged` proof, broken packaged asset/save/`userData` behavior, software rendering on expected hardware without understood cause, leaked PIDs/listeners/profiles, stale/mismatched source/package fingerprints, or unresolved checkpoint regressions. Performance neutrality is not failure; unsupported Electron 31 is not retained for a neutral result.

# SpaceFace public beta — maturity report and the one plan (2026-10-23)

Owner request (2026-10-23): scour the repo, report how mature each game system is, fix bugs, polish the
frontend, and get the game ready to release as a **beta**. Collect 20–30 tasks from the build map,
review and expand them, find 20–30 more, unify them into one direction, and implement all of them.

Thread: `claude-beta-oct23` (NOW.md row). Work happens in a separate clone on `master` and lands on
`origin/master` by exact-path commits. Implementers are Sonnet subagents. Reviews are by Codex
(GPT 6.1 Sol, highest effort) on both the existing code and every wave this campaign lands.

Evidence behind this report: four read-only scout passes (core play, progression and saves, frontend
and first ten minutes, release engineering), two Codex reviews (backend bug hunt and a review of everything
landed since 2026-10-19), and a clean-master run of the fast gate (`npm run check:baseline`).

---

## 0. The verdict in plain words

SpaceFace is much deeper than a typical beta. Its core toy (flying, the Line, rocks as weapons, the five
powers) is carefully built and well tested. The save system is better than most shipped indie games.
The ways a stranger's beta goes wrong are almost all **at the edges**:

1. **When something breaks, nobody is told.** The shipped build's error message can never appear. The
   desktop app can vanish silently on a failed start. If the physics engine fails to start, the ship
   ignores every key with no explanation.
2. **A handful of real logic bugs can cost progress.** Codex found ten. The worst: an older recovery
   copy can overwrite newer progress, loading a save can keep "already discovered" history from the run
   you left, and dying with contract cargo can delete your own cargo twice. A second Codex pass over the
   last three days of landed work found ten more, almost all *wiring* misses: features that were built but
   never saved (mail history), never scheduled (eight faction systems), never heard (a release receipt) or
   never reachable (a paid extraction that cannot complete).
3. **Weak laptops are misdetected.** Common AMD laptops are treated as gaming GPUs and run at full cost.
4. **The fast health check is red on master**, so regressions are invisible.
5. **There is no beta identity.** No "beta" label, changelog, feedback route or way to copy diagnostics.

None of these needs new content. The plan is to make the game you already have trustworthy.

## 2. The direction — one game, finished at the edges

**The beta is the game that already exists, made trustworthy.** Every task in this plan serves one of
five promises a stranger relies on without knowing it. A task that serves none of them is not beta work.

| Promise | A stranger's sentence | What it rules in | What it rules out |
|---|---|---|---|
| **Start** | "It opened, on my machine." | Kind failure screens, desktop shell that never vanishes, right defaults on weak laptops, retail boot smoke | New renderers, dropping authored visuals to pass a number |
| **Keep** | "It never lost my stuff." | Save/restore correctness, cargo and contract settlement, settings that persist, old-save fixtures | New save fields without migration and caps |
| **Read** | "I always knew what was going on." | No internal ids or overlaps on the glass, clear first contract, plain copy, reachable controls | Redesigns outside ORRERY; more HUD text |
| **Feel** | "The rope and the rocks feel great." | Bugs in damage, beams, catch-up physics, Line voice; Crucible launch | New powers, new factions, new books |
| **Report** | "When it broke, I could tell them." | Visible errors, copy-diagnostics, beta label, changelog, feedback link, green gates | Telemetry that phones home (no network by design) |

**Refusals for this campaign.** No new content packs, factions, books, minigames or modes. No visual
redesign outside ORRERY. No re-recording goldens to pass. No edits inside another live lane's changed hunks.
The rich backlog in `build_map.md` §31–§34 (THE WEIGHT) stays the post-beta plan; it is not cut, it is next.

**Order.** Report and Start first (they turn every later bug into a usable report). Keep second (data loss
is the unforgivable class). Feel and Read in parallel after. Green runs throughout and closes the campaign.

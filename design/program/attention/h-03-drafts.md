# H-03 drafts — three personas

## Drifter
The shop list is where a broke pilot lives. Every stock part deserves one line of yard truth —
who makes it, who broke it, why it's cheap. Keep to the maker field mostly; casualties only
where a death is actually plausible (scanner, quarantine, shield booster).

## Archivist
Overlays should read like accession notes: provenance, prior owners, the receipt's other side.
Casualties belong where the record would remember (the first crew to need a quarantine locker
didn't have one).

## Accountant
Cost: ~26 one-line entries in an existing Object.freeze map. Zero consumers change; codex
already renders maker/casualty conditionally. Rejected: new `sentence` fields in modules.js
(dirty-risk, UI copy already exists), part-install tutorial lines (V-02 territory).

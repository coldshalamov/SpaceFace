# NXI-022 — Do not offer a scripted machine proxy as a dynamic tow body

**Assignment:** INFERENCE · bounded implementation · P2  
**Initial admission:** OPEN (snapshot only).  
**Live status:** SHIPPED — `design/program/INFERENCE_IDEAS.md`, commit `6eca0bd9a` (2026-10-02, thread glm-nxi022).  
**Related strong packet:** [NXB-006](../build/NXB-006.md) — not a second copy of its full assignment.

## Outcome

`isAttachable` (`src/systems/tetherGameplay.js`) now applies the existing `physicsBody: false`
exclusion to the advertised acquisition result, so a scripted machine proxy is never offered as
throwable cargo, while an actual loose payload beside it still is:

- `physicsBody === false` (scripted pose, no body in the SG-02 index) → not attachable. Covers
  world-site non-solid component proxies, precursor machines (`machine`), fauna, and closed-form
  lane far-actors.
- World-site machinery roles (`world_site_component`, `world_site_collision`) are not attachable
  even when solid (their kinematic body is station-class terrain whose cycle the site runtime
  owns) — machinery was not converted to dynamic bodies.
- Neighboring successes preserved: stations and asteroids (real kinematic body objects), mines and
  claim beacons (`masslineTetherable: true` on real/default bodies), and fresh survival-round
  wrecks (VERB-12 bypass) all stay latchable; the released site payload (dynamic sensor body,
  NXB-006) stays offered.

Focused proof: `test/nxi-022-kinematic-proxy-not-offered.test.mjs` (seed 4242) — all three proxy
shapes denied, payload offered, neighbors green. Neighboring tether suites re-run green
(massline-acquisition-preview, f17-latch-repair, massline-tractor-throw-drill, twin-bridle, etc.);
the one failure observed (`f14-hauler-worth-catching`, missing liner itinerary) reproduces without
this change and sits in traffic.js, owned by the live pb-ten-lanes row — logged in the demo
defect ledger, not caused by this unit.

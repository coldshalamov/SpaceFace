## Confidence vocabulary

**Source fact:** visible in a read source or exact search excerpt at the pinned commit. **Repository-reported:** a plan/triage/PR says it; not independently executed here. **Design decision:** a proposed behavior selected by this package. **Conditional repair:** run the named counterexample first; fix only a demonstrated mismatch. **Gameplay unproven:** no visual/audio/feel/performance claim is established by reading source.

For all packets, numeric API/game constants quoted as existing behavior come from their source; any new example quantity is a test fixture, not a balancing prescription. Do not adopt old performance measurements from dated reports as current host evidence. All current owner rules and the user's newer instructions outrank this planning snapshot.

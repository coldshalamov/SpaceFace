## The decided change

Repair and site persistence are existing foundations. This extension specifies a two-stage material-backed repair that can be left, resumed and interrupted without consuming the same inputs twice.

**Existing ownership to reuse:** SF-077, SF-094, SF-101, SF-274. Read the matching existing packet/implementation before changing its seam. An equivalent working result closes this assignment as already satisfied; it is never permission to invent a replacement feature.

## Implementation sequence

1. Choose one current repairable machine; split its existing operation into a material admission stage and a work-progress stage only if its owner already supports such phases.
2. Admit real delivered repair goods through cargo/site owners, retain the accepted work receipt, and resume from that durable state after leaving or loading.
3. Restore only the repaired function and its operating visual state; partial repair remains useful evidence rather than resetting the whole machine or paying the final reward early.

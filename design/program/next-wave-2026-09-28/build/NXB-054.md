## Implementation sequence

1. Use the current map/watchlist/mission identities for two tracked destinations and retain the distinction between tracked interest and active navigation.
2. Search/filter the existing known map without exposing hidden contacts; each result states whether its location/access is known or merely reported.
3. Selecting a service or mission may update its existing tracking, but starting navigation is an explicit current action against a revalidated reachable destination.

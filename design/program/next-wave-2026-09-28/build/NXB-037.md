## The decided change

Shared journeys and once-only rewards are existing work. This packet defines shared-object semantics: an escort, recovery or investigation can concern the same durable actor/lot while keeping distinct obligations.

**Existing ownership to reuse:** SF-108, SF-144, SF-146, SF-278. Read the matching existing packet/implementation before changing its seam. An equivalent working result closes this assignment as already satisfied; it is never permission to invent a replacement feature.

## Implementation sequence

1. Use the existing stable object/lot record for the shared subject; each mission owns only its objective and accepted terms.
2. Classify an observed event as shareable evidence, an exclusive material transfer or a single destruction fact. Evidence may inform several jobs; an exclusive quantity cannot be spent twice.
3. On completion/cancel, release only that mission's claim and do not despawn a body still used by another mission or the world.

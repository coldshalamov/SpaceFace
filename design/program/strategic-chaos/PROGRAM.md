Add one finite supply consequence (SC-09) and one remembered person (SC-10). Compose these capabilities into SC-11, one operation at a time. Final three-operation authoring acceptance for SC-12 uses that real content; it does not block its foundation work.

Dependencies express acceptance prerequisites. They do not require every teammate to finish every unrelated task before useful source work can start. Read current source, not stale status prose.

## Scheduling rules

Do not dispatch two writers onto shared targeting, `wingmen`, the encounter director, the missions family, law, economy, presentation arbitration or the build map. Split exact hunks only after inspection; a category name is not ownership of all files below it. New authored scenario modules and focused tests can proceed in parallel with shared-owner integration. A lead integrates by content and reruns the affected route; no broad checkout replacement, automatic merge or branch absorption.

The command `node scripts/strategic-chaos.mjs brief SC-03` prints an assignment. It does not claim a board row, create a paid chat, start an agent, change task status or execute implementation. The human/controller dispatching that assignment uses the existing program surfaces.

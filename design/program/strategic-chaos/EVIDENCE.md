The adapter’s missing-source behavior is tested; that is not a measured failure of SpaceFace itself.

## How evidence must advance

Source inspection → focused new-tool checks → exact-tree native owner execution → appropriate ordinary-route evidence → visual/performance review where relevant. These are distinct claims, not an automatic promotion ladder. An imported JSON flag, static test count or generated screenshot placeholder cannot substitute for the corresponding execution.

A receipt count proves observed coverage, not necessarily actor-linked causality. A strategy comparison proves the supplied metric differences for matched metadata, not authenticity, balance or fun. Strengthen those claims at the owning producer and real player route when building the commissions.

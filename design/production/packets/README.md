# Production Packet Scope

Every file in this folder is a manual campaign artifact. A packet becomes operative only when a
user/lead or activated controller names that exact packet and reconciles its current state, dependencies,
leases, and writable paths. Discovery, search results, or a stale `status:` field do not activate it.

Outside an activated campaign, packets are retained implementation/control-plane proposals. They do
not make ordinary agents submit-only, forbid coherent integration, or override scoped `AGENTS.md`, the
current task, architecture, program status, Git state, live locks, checks, or player-facing evidence.

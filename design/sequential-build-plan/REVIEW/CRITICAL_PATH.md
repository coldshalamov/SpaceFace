# CRITICAL PATH — the smallest subset that delivers "optimal, professional, beautiful, fun"

> Cross-reference: `REVIEWER_DECISIONS.md` Q27. This is the cut line. Everything
> above the line, done excellently, ships a game that clears the four bars.
> Everything below it is Wave-2 — valuable, but the game is not *missing its
> identity* without it. When scope pressure rises, cut from the **bottom of this
> list upward**, never from the Toy.

---

## The one-sentence version

**Make the massline a toy, make combat physical, make one planet and one wreck
unforgettable, make the world alive and criminal, make it look like a shipped
game — then prove it in a 30-minute corridor.**

## Cut order under scope pressure (last → first to go)

1. **Asteroid-ops corridor slice (23)** — the corridor can run its industry beat on
   the claim stage-1 alone; survey depth can wait.
2. **Ceres recomposition full pass (19)** — degrade to "two pockets + the Cathedral
   placed," keep the separation law, defer the third/fourth pocket.
3. **Visual families (21)** — degrade to one ship family only; keep the pipeline
   (the pipeline is the point; replication is the luxury).
4. **Heist loop (18)** — degrade to "escort-or-rob one scheduled capsule," keep the
   heat/fence intents; defer patrol-escort complexity. **Do not cut entirely** —
   GTA is identity.
5. **Field kernel consumers (11)** — ship Well + Repulsor, defer the Cone.
6. **Nothing in ARC 1, and not SF-08/09/10, SF-14, SF-17, SF-20, SF-30, SF-32,
   SF-33.** These are the identity. If they can't all land, the answer is more time,
   not fewer bars.

## The four bars, mapped

- **Optimal:** PD controllers not kinematic animations (4, 6); impulse through
  physics authority (8); instanced/SDF/flow-field VFX (9, 11, 12, 22); predictor at
  10–20 Hz interpolated (5); compound colliders not mesh rebuilds (7).
- **Professional:** named techniques in every brief; ≥5 forbidden shortcuts each;
  acceptance = checks + player-route captures, never green-from-source.
- **Beautiful:** Cathedral + planet (12, 17); three-scale families (21); one VFX
  language with the anti-"HTML-bloom" massline (22); anti-cartoon ledger art (20).
- **Fun:** the toy (1–6), expendable-swarm physics combat (8–11), the trailer
  planet (12), GTA crime (18), emergent styles from combined primitives — and
  restraint everywhere else so these land polished instead of everything landing
  shallow.

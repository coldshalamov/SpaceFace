## Dispatch rules

- A `VISION-YES` task is not accepted from source inspection alone.
- A `VISION-RECOMMENDED` task may reach `FOCUSED_GREEN` through a backend agent, but normally needs visual review for `VISUALLY_ACCEPTED` or integrated player-facing signoff.
- A strong visual agent should not be spent on pure telemetry, control-law, response-kernel, or repository-truth work unless the live blocker is visual.
- A visual agent must still obey deterministic simulation, physics authority, save, route, and single-writer contracts. Vision does not excuse architecture.

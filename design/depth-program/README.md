# Depth Program Map

This folder turns latent SpaceFace lore, systems, places, factions, and content into things the
player can see, visit, use, and remember. It owns detailed Depth scope; it is **not** a second global
status system.

## Read order

1. [`../program/README.md`](../program/README.md) — sole whole-program status and pickup surface.
2. [`../program/02_REMAINING_WORK.md`](../program/02_REMAINING_WORK.md) — admitted Depth chunks and
   their current next outcomes.
3. [`BUILD_PLAN.md`](BUILD_PLAN.md) — canonical 31-chunk Depth scope, dependencies, and acceptance
   intent.
4. [`PROGRESS_LEDGER.md`](PROGRESS_LEDGER.md) — detailed receipts and chunk evidence; it cannot
   promote global completion.
5. The activated pipeline/spec below, then current code/checks/player evidence.

## Status and activation

- [`../program/02_REMAINING_WORK.md`](../program/02_REMAINING_WORK.md) owns the live Depth roll-up.
- The detailed ledger records evidence and remaining chunk detail. `DONE`, `IN-PROGRESS`, or a green
  narrow check there does not replace normal-route, visual, full-regression, and git proof.
- Valuable Depth-adjacent ideas not yet admitted belong in
  [`../program/06_RETAINED_FUTURE_BACKLOG.md`](../program/06_RETAINED_FUTURE_BACKLOG.md), not in a
  new competing queue.
- Before dispatch, check current file ownership and asset/graphics locks. Asset outcomes never
  inherit historical triangle/byte counts as quality ceilings; use current framing and measured
  performance.
- Canon comes from [`../../docs/worldbuilding/README.md`](../../docs/worldbuilding/README.md), place
  identity from [`../world-identity/README.md`](../world-identity/README.md), technical contracts
  from [`../../ARCHITECTURE.md`](../../ARCHITECTURE.md), and game-design intent from
  [`../GDD_2_0.md`](../GDD_2_0.md).

When prose, the ledger, and the live tree disagree, preserve the idea, correct the record, and trust
the current code/check/player-route evidence for implementation truth.

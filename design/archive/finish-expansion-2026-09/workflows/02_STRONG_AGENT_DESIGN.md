# Strong-agent design and diagnostic campaigns

This is distinct from the repository's directed INFERENCE lane. Use it when the correct production change is not yet known.

## Entry packet

Provide current build identity, relevant source authority, a player route, observed symptom and supporting concept. Example: “At the current G-mode fight, simultaneous target/rig use demands too much pointer precision,” or “The Mason looks busy but no workpiece changes.” Do not prescribe an implementation before checking the actual mechanism.

## Investigation sequence

Reproduce under the current ordinary route. Trace input → intent → capability admission → authority operation → contact/outcome → presentation → persistence. Mark the first broken or weak link. Compare with an already-good route inside SpaceFace before seeking outside inspiration.

For a design weakness, sketch a small number of genuinely different mechanics. Each must state the player's gestures, preparation, visible consequence, counter, resource cost and failure branch. Reject options that require a new subsystem when a current owner can do the work.

Prototype one in the existing lab or source owner behind the current development convention. The prototype uses actual masses, controls and art scale. It must not become a superior parallel game with better test-only assets or relaxed rules.

Test a positive case, a negative case and an overloaded/awkward case. Examples: light/heavy coupling; dynamic/scripted target; intended mission solution, late arrival and destroyed objective. If the law creates unintended energy, free rewards or control theft, fix the law before polishing the cue.

## Decision output

Choose one production intervention, a current owner path, the smallest required supporting changes and the ordinary-route acceptance. Explain why alternatives were not selected. Convert the decision into a native packet or bounded INFERENCE item only after the change is specific enough for a worker to implement without inventing the game.

## Stop condition

The campaign ends with implemented/reviewed improvement, or a clear falsified hypothesis plus another productive task. Do not produce an endless report series. Do not demand a subjective human approval for every technical detail, but do not fabricate that approval either.

# Design and engineering risks

This is a **proposal risk register**, not a second live defect ledger. Put reproduced bugs in the current repository ledger.

| Risk | Early warning | Mitigation / cut decision |
|---|---|---|
| Foundational architecture swallows content | Weeks of generalized graphs with no improved scene | Admit one local work cycle; generalize after three real consumers |
| Every alien becomes a fighter | Same target/attack behavior under new silhouettes | Preserve passive drives and give capture, diversion and observation real rewards |
| Machine logistics is cosmetic | Robot moves but inventory/site never changes | Physical token/workpiece custody and downstream state are acceptance requirements |
| Goo is a duplicate debuff | New weapon only changes color and status duration | Require real contact, surface state, transfer/bridge or a distinct utility; otherwise reuse Tarburst |
| Goo ruins control | Constant heavy handling penalty and no counter | Local readable buildup, caps, useful purge/heat options and bounded denial |
| Solver becomes unstable | Overlap/zero span/mass extremes create spikes | Reuse authority/constraints, soften singularities, test dt and deterministic breaking |
| Vacuum metaphors become broken laws | Sail/parasite deletes momentum with no source | Explicit medium/energy/coupling rule or cut the device |
| Ancient fields erase game rules | Universal stop/teleport with no counter | Finite geometry, explicit targets, resource and recovery; nonlocal tricks optional |
| Quarantine becomes punishment management | Every station refuses, travel stalls | Limited local consequences and reachable remedy/refuge; normal play remains viable |
| Dynamic world corrupts saves | Visit catch-up duplicates actors and events | Stable IDs, bounded stage graph, one writer and one settlement |
| New UI information starts a redesign | Agent adds new chrome/tokens/library | Use ORRERY and current components; task-required information only |
| More VFX means less readable | Main hull or next threat disappears | Preserve shape, prioritize causal forms, optimize supports and overlap rather than remove identity |
| Asset finish is gallery-only | Great Blender image, broken game import | Production renderer and cold normal route determine acceptance |
| Performance goal removes beauty | Reduced actors/detail declared success | Same-picture causal optimization and explicit min-spec testing |
| Status says done, player cannot use it | Debug path only or obsolete receipt | Public acquisition-action-feedback-persistence chain |
| Repeated old plans poison work | Already-fixed cruise/G bugs reappear | Pin observations, revalidate current source, map outcomes and retire active stale wording |
| Open-ended ambition prevents finish | Optional features become critical prerequisites | Finite finish manifest and selected subset; no quota for every catalog row |
| Review becomes its own product | Reports and screenshots exceed useful changes | One repro, one intervention, actual inspection, integrate or cut |

## Earlier brainstorm ideas requiring correction

“Momentum leech stores momentum” is not a sufficient mechanical spec. Momentum is vectorial; energy and momentum storage/release need a declared body/source/frame and budget. Do not implement an energy-creating replay kick without calling it a powered game rule and bounding it.

“Asymmetric coating changes handling” requires an actual offset mass/force or a explicitly stylized response rule. Painting one side of a ship with cosmetic goo does not automatically change its inertia tensor.

“Suppression makes goo inert/calcified” was a proposed cross-reaction, not established canon. Coherence loss alone need not kill or mineralize tissue. Admit a material reaction only with a distinct mechanism and compatible source direction.

“Hundreds of species cheaply generated from a grammar” may save art work but can dilute identity and create test explosion. Finish a small number of roles with meaningful relationships first.

## Pairwise coverage is not an all-combinations guarantee

Start with high-risk pairs: physical target type × tool; material × force; transaction × interruption; field × frame; UI × device; asset generation × lifecycle. Then run a few deliberately dense triples such as goo + Massline + concussion or machine workpiece + moving field + save/reload. Use actual causal failures to expand coverage. Exhaustive cross-product testing of every catalog item is neither promised nor necessary before the selected scope exists.

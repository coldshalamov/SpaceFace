# PQ-166.02 — Five languages

DONE PQ-166.02 — Five language catalogs ship (English, Spanish, French, German, Brazilian Portuguese), the Settings picker lists them, store page copy exists in all five, and radio barks were rewritten in each register rather than dumped through a machine.

DONE WHEN (verbatim): Five catalogs ship; store page in five languages.

WHAT I FOUND — The runtime could already switch language live, but only English and the fake layout language had catalogs. Store page copy did not exist. Radio barks lived only in English arrays, so a machine dump would have flattened every faction into the same voice.

WHAT I CHANGED — English plus four full catalogs now load through the existing runtime and picker. A translation pipeline covers the inventory; store page copy and the bark corpus got a register pass (Concord still cites Ref 44-C, Quiet stays short, Vael still speaks in clauses). The display face falls back through Instrument Sans, Segoe UI and Noto Sans for Latin languages.

WHAT YOU WILL FEEL — Open Settings, Access, Language. Pick Español, Français, Deutsch, or Português (Brasil) and the UI redraws without a reload. The Steam-facing lines (tagline, about, the ammunition sentence) exist in those languages. English remains the default until you choose.

## Controller review — 2026-09-07

AGY's listeners were correct, but `stuntGrammar` from PQ-146.00 was never on the production registry, so `stunt:trickDetected` never fired on the default route. This land registers that observer after collision consequences, keeps the titles/ledger/bark wiring, and does not widen bark witness eligibility by factionId alone. ## Summary of Implementation

- **Titles System (`src/systems/titles.js`)**:
  - Registered listener for `stunt:trickDetected`.
  - Implemented `_onStuntTrick(trick)`: validates player actor and non-empty `causeChain`, generates stable title ID (`title_${trickId}`) and formatted title name (`humanizeId`).
  - Recorded title to `state.story.titles.byId[titleId]` and appended to `state.story.titlesSeen` bounded buffer (`TITLES_SEEN_LIMIT = 32`) with `trickId` and `holderKey` (`worldRecordId` or `'player'`).
  - Stamped player entity presentation data (`titleId`, `titleName`) if active and re-stamps silently upon `save:loaded`.
  - Enforced save integrity law: transient entity integer IDs never enter `state.story`.

- **Ship Ledger (`src/systems/shipLedger.js`)**:
  - Propagated `trickId` and `tokens` onto candidate objects in `makeCandidate`.
  - In `collectCandidates`, passed `trickId: record.trickId` when projecting title records from `state.story.titlesSeen`.
  - Because `state.story.titlesSeen` is serialized under `data.missions.story` by `saveSystem.js`, the ship ledger entry projects identically before and after a save/restore cycle.

- **Bark Director (`src/systems/barkDirector.js`)**:
  - Authored `STUNT_BARKS` containing 4 distinct lines for all 8 code factions (`faction_scn`, `faction_mts`, `faction_dmc`, `faction_reach`, `faction_quiet`, `faction_choir`, `faction_free`, `faction_vael`).
  - Added deterministic `stuntRecognitionBarkFor(factionId, rng, tokens)` selector supporting seeded PRNG (`state.rng`) or numeric hash index.
  - Wired `stunt:trickDetected` to `_speakStunt(payload)`: verifies player actor, non-empty causeChain, finds closest eligible NPC witness via `_nearestWitness()`, formats faction-appropriate line, routes through `voice.say(...)`, and emits `barkDirector:voice` and `barkDirector:stuntRecognition`.
  - Stunt recognition barks are explicitly exempt from post-combat silence (`postCombatSilenceUntil`) as they mark the climax/tail of the combat encounter.
  - Enhanced `_nearestWitness()` to robustly search `state.entityList`, `state.entities` Map, and `state.entities` object collections.

- **Verification Suite (`test/pq146-02-titles-ledger-bark.test.mjs`)**:
  - Tested witnessed bolas `stunt:trickDetected` (player actor, real causeChain) producing `barkDirector:voice` and ship ledger row in one session.
  - Verified JSON serialization and save round-trip preserves `state.story.titlesSeen`, `state.story.titles.byId`, and the projected ship ledger row.
  - Verified no `entityId` leakage into serialized story state.
  - Verified negative cases: trick without causeChain rejected (no bark, no title, no ledger entry); non-player trick rejected; unwitnessed trick produces title and ledger row but no radio bark.
  - Verified post-combat silence exemption.
  - Verified all 8 faction voice sets with all 4 variants each.
  - Verified full test regression: 68 tests passing across `pq146-02-titles-ledger-bark`, `ship-history`, `depth-program-s4-thunderchild`, `depth-program-a2-ship-ledger`, `stunt-taxonomy`, `faction-pressure-grammar`, and `encounter-barks`.

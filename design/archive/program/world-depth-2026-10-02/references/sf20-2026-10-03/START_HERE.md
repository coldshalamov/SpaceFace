# SpaceFace — Worlds With Work To Do

## Twenty authored additions, with agent-ready production plans

Pinned source: `1e0cf9499613b7c3acad10f34739278136d3d469` • Prepared 2026-10-03 • Status: DESIGN PACKAGE, NOT IMPLEMENTED GAME CONTENT

Open `REPORT.pdf` for the illustrated book or `INDEX.html` for the offline, self-contained illustrated report. Individual concept packets live in `concepts/`. The machine-readable `data/agent_tasks.json` contains 125 proposed work packets, including five shared foundation tasks.

The core recommendation is to strengthen recognizable encounters and consequences on top of the existing engine. Start with 19, 01, 03, 07, 18 and 05. Do not activate all twenty at once.

## Included

Twenty complete design dossiers; twenty original procedural concept-render PNGs; twenty vector plan studies; twenty inspectable non-shipping GLB form blockouts; a repository audit with pinned sources; model/animation/asset pipeline; ownership and save integration map; test and accessibility plan; staged roadmap; structured concept/asset/dialogue/task data; an offline gallery; and a package validator.

The art is accurately labeled procedural reference work. The image generator's unrelated posters were rejected, not mislabeled as these designs. The GLBs are form studies—not production Forge assets, collision models or rigged characters. The detailed text supplies the build instructions for those future assets.

No repository files were changed or PR opened. Source was inspected through GitHub; gameplay, frame rates and actual model loading were not tested here. Package validation results are in `VALIDATION.md` and must not be confused with game acceptance.

## Agent handoff

Read `production/REPO_AUDIT.md`, `production/ASSET_PIPELINE.md`, `production/INTEGRATION_MAP.md`, `production/ROADMAP.md` and `production/TEST_PLAN.md`. Then take one concept's A packet, resolve current owners and duplicates, and complete its normal-route vertical slice before expanding. `production/SOURCES.md` distinguishes read evidence from unverified adjacent seams.

The package is not a new source of authority over newer repository instructions or the owner's canon. Candidate coordinates, behavior timings, masses and resource caps are proposed tuning values requiring validation. A blank canonical site id is intentionally not invented; choosing a safe existing site is a defined implementation task.

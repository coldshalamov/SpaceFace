# M-03 drafts — authored encounters

## Drifter

`bounty_notice` is five lines of professional menace, all "nothing personal." A working
hunter has opinions about the posting itself — the fee, the poster, the last hull sent.
Two more lines in that voice and the encounter stops sounding like a form letter.

`convoy_depart` and `ambush_spring` are thinner still. A convoy leaving should sound like
a crew that knows the lane is watched; an ambush springing should name what it smelled.

## Archivist

Continuity hooks exist: `hunter_iask`, `hunter_sorrel`, `hunter_vane` already speak as
named people, and the proving-ground captains (Sable Iask, Redcut Sorrel) are the same
names the 47-A branch chain fields. New lines should echo that web — board references,
prior hunters, the toll board's memory — so encounters talk about a world, not a spawn.

## Set Dresser

The corpora are the wallpaper the player actually reads while physics runs. Keep the
register per family: bounty = professional contempt; ambush = the smell of a set lane;
convoy = a crew talking shop on the way out.

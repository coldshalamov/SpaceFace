# H-01 drafts — three personas

## The Drifter (working-class regular)
The hitch he flies is somebody's old work truck. He wants the world to admit that: a paint
that looks like it already did a tour, a name that sounds like it was welded on by a crew,
not generated by a registry. Draft: (a) +12 names in `HULL_NAME_BANK` that sound owned —
"Second Shift", "Salt Line" style: debts, shifts, dock humor ("Late Fees", "Second Coat",
"Berth Nine"). (b) +4 hull paints worn by work — a cargo-line ochre, a toll-booth grey,
a freezer-coat white, a scrapper's rust red — each with a yard-voice sentence. (c) +3 accents:
seam-marking paint colors miners actually use (claim-gold, cable-loom blue, dead-light amber).

## The Archivist (continuity and memory)
A hull is a record. The starters should carry the dead that made them: the Tessera already has
Maera Vols — say so where the codex admits it; the Pelican's frame is older than the crew that
mines it; the Wasp's pattern killed its own test pilots. Draft: `casualty` lines on
`ship_kestrel` / `ship_pelican` / `ship_wasp` in `HULL_OVERLAYS` — one named consequence each,
consistent with `CHARACTER_OVERLAYS` canon (Vols already filed; Senna welds names in keels —
established on `ship_ironback`).

## The Set Dresser (visual storyteller)
The hull should read its job before the text does. More coat vocabulary: paints that read as
professions (liner white, ore-dust, impound grey) so the same Hitch silhouette carries different
lives. Draft overlaps the Drifter on paints/accents but argues for livery-realistic colors
(mercantile cream, tow-line orange, quarantine grey) over joke names.

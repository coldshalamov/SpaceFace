# 03 · Physical play, encounter craft and Swarm

**Parents:** PQ-141, 390, 392, 393, 448, 475; Swarm 456, 270, 453, 481.
Comparison lenses: the readable physical improvisation associated with Teardown/Just Cause and
the choice-execution-return structure associated with Hades. These are design analogies, not a
claim that SpaceFace has their production scale or that importing their features guarantees success.

## The reference encounter

Use an existing working pocket with a freighter, an attacker, useful mass, an escape bearing and
a plausible witness. Every body must have an independent reason to be there. Prefer existing
Ceres actors and authored machinery, but do not duplicate the tender, salvor or Orchard work in
open PRs. Verify the current placed geometry before selecting the exact cast.

The encounter supports defend, disable/tow, steal, improvise and leave. The player can throw an
attacker into another body; collateral can spill existing finite cargo; a real witness can respond;
the player can recover a pod or flee. These are opportunities, not an eleven-step cutscene.
An ordinary failed throw must remain understandable and recoverable.

### Build in three bounded passes

1. **Opportunity:** identify safe starting relationships, available throwable bodies, target
   contrast and an escape route. Use current spawners and physical owners; no scripted impulses.
2. **Causality:** prove released-body lineage → actual contact → damage → finite aftermath →
   witness/law response. Cover a miss, an unwitnessed incident, a nonlethal impact and interrupted
   ownership. Never claim a crime occurred merely because an encounter clock advanced.
3. **Readability:** route impact, warning and response through existing VFX/audio/voice owners.
   Preserve the current gameplay camera and meaningful reduced-motion/flash equivalents.

Use the existing `proofSixtySeconds` machinery where it observes the claim. Its score and capture
must not be substituted for a novice successfully discovering the verb. Retain original seeds and
add a small held-out set rather than tuning a single perfect demonstration.

## Encounter grammar

Author situations as **useful mass + motive + interference + escape + consequence**. Example:
a tug attempts to free a cargo frame while raiders cut the line and a patrol approaches.
Three answers should differ in cost or aftermath, not only in animation: shoot the raider,
swing it into a frame, or tow the cargo through a dangerous short route.

Create variants by changing physical relationships and actor goals, not multiplying HP or writing
another bark. Reserve enemy body-launch behavior for row 392 after its incoming-mass cue exists.
Do not add unseen attacks or player-hull knockback to make physics appear more dramatic.

## Swarm: a complete loop before a bigger catalog

First finish 456's actual round/start/transition defects. Then implement 270's existing phase-C
journey and arsenal scope. Maintain later phase boundaries: the cabinet presentation does not
silently authorize broadcast hosts, construction mode, a pilot roster or global boards.

For a bounded run, make each choice answer a physical question: better heavy towing with slower
reversal, field control at a heat cost, or precision impacts with less forgiving recovery.
The same offer set must admit more than one viable approach. Show the consequence before the next
shop. A result card reads genuine run facts; retry clears transient owners and pays nothing twice.

The recurring test sequence is launch → survive a real round → choose an upgrade → use it → reach
an escalation → finish or die → inspect truthful results → restart. A direct setter that jumps the
run to a result phase is fixture setup, not public-route evidence.

## Boss maturation

CLOUD-10 exposes the existing score's tell/counter/recovery for one boss first. Only after that
works should row 448 author detachable plates and physical phase changes. Detached plates need
combat ownership, collision identity, bounded lifetime and save/revisit behavior; a visual detach
without those contracts is not a new weapon. One boss is the initial production slice, not eight.

## Evidence to retain

Keep the exact source revision, ordinary entry, causal receipts, affected lifecycle tests and a
short shipping-camera capture when available. Ask an observer what they thought happened before
explaining it. Engineering pass plus an unintelligible clip is still an open presentation task.
No new replay/export platform is required to prove a good encounter.

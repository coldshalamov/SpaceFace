# 56 — DIFFICULTY & ACCESSIBILITY

Difficulty policy is locked (11: composition, not HP sponges). This doc adds the levers and
the accessibility floor.

## Difficulty levers (player-facing, settings-level)

- **Encounter pressure**: spawn cadence / wave size scalar.
- **Enemy accuracy**: spread/lead error scalar (not damage).
- **Economy ease**: price/reward scalar for relaxed playthroughs.
- **Ironman toggle**: optional permadeath for the other kind of player.
- Named presets (Story / Pilot / Veteran / Ironman) that set the above; individual sliders
  stay exposed.

## Accessibility floor (most exists — wire and verify)

- Colorblind palettes + IFF shape redundancy (exists; verify every new glyph in this program
  gets a shape).
- Reduced motion (kills hit-stop, trail density) and reduced flash (31's variants) — default
  respect for OS preference.
- Full remapping + gamepad parity (bindings exist; new verbs get bindings in the same packet).
- Screen-shake slider including zero (10).
- Subtitle/caption equivalents for audio-critical cues (tether strain gets the 34 gradient;
  burn-up roar gets the HUD proximity cue — every audio tell has a visual twin).
- One-handed flight assist: auto-face travel + hold-to-fire options.

## Acceptance

- Audit route per setting; a11y review on every new VFX/glyph from 31–39 (checklist in the
  packet template).

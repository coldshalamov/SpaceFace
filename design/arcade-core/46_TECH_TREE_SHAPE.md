# 46 — TECH TREE SHAPE: four fantasies, feat-gated

`tech.js` (28 nodes) exists. Restructure target: four branches named for *what you become*,
fed by 01's XP channel, with **feat gates** that teach the physics verbs.

## Branches

- **KINESIS** — impulse & gravity play: concussion upgrades, field strength, well duration,
  the Impulse Lance (03). Feat gates: N terrain smashes, N well-collapses, a chain of 3+.
- **BOND** — the Massline tree: winch tiers, line capacity (two lines?), anchor authority,
  tow efficiency. Feats: N tether kills, a successful capital-tow (20), N slingshot
  deployments.
- **INDUSTRY** — mining/factory: beam tiers, scoop, claim slots, convoy escorts. Feats:
  perfect resonance mines (42), N cores cracked, a defended raid (08).
- **GHOST** — information & evasion: sensor range, scan evasion, jammer resistance, cloak-
  adjacent toys. Feats: N scans run (49), N ambushes survived, a ghost-ship discovery (28).

## Rules

- Feats are *tracked quietly* and revealed on unlock ("the tree noticed what you did") — a
  delightful surprise, not a checklist grind.
- Every branch's capstone is a **new verb**, not a stat: e.g. Kinesis capstone = deployable
  *paired* wells (slingshot a target between two fields); Bond capstone = the two-line rig.
- Respec: allowed at stations for credits; the tree is a commitment, not a trap.
- XP economy sized so a combat-main player and an industry-main player both cap ~one branch
  by mid-game and ~two by endgame.

## Acceptance

- Sim audit: XP inflow by playstyle vs node costs; feat tracking per feat; capstone verbs
  work in bot routes.

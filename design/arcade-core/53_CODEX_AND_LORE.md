# 53 — CODEX & LORE: the collectible second game

Codex exists (K). Make it the completionist engine: every system in this program writes
*into* it.

## Entry sources

- **Black boxes** (26): each tells a wreck's story in 3–5 short logs. The Double Wreck (28)
  interleaves two perspectives.
- **Scan firsts**: first scan of each NPC type (18), anomaly (19), landmark (25), planet
  archetype (23) writes an entry.
- **Deed entries**: your first burn-up, first chain-3, first capital kill — written as
  *news-style retellings* (27's voice), not achievement toasts.
- **Bestiary pages**: fill in as you fight; a completed page shows the counter-play note
  ("Leaders scatter when broken") — codex as the game's manual, discovered.
- **Secrets** (30): their own tab, with "???" placeholders that nag pleasantly.

## Rules

- Entries are short (2–6 lines), 29-voiced, and *useful* when they can be (counters, prices,
  rumors).
- Completion % exists but is never announced in-world (I-4); it's a codex-screen quiet corner.
- Lore never contradicts sim truth: if the codex says a thing behaves a way, it does (I-9
  spirit).

## Acceptance

- Audit: every bestiary/landmark/anomaly entry has a tested acquisition path.

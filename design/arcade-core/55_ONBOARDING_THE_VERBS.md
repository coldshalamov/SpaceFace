# 55 — ONBOARDING THE VERBS: teaching the physics game

GDD §8.2 owns the first-fifteen-minutes pacing. This inserts the Arcade Core verbs into that
spine so every player *does* each signature move once, early, safely.

## The verb beats (woven into existing steps)

1. **The shove** (~minute 4): a scripted crippled drone on a collision drift; the game hands
   you a concussion shot and a rock. It smashes. 02's fireball plays. No words needed — one
   quiet objective line ("put it into the rock").
2. **The inhale** (right after): the drone's burst is mote-like; fly through it. The pickup
   ladder plays. The player has now done the entire core loop once.
3. **The swing** (derelict beat exists): tether + perpendicular burn + cut, with a checkpoint
   ring placed at the release tangent (50's language).
4. **The well** (mid-game unlock mission): a mote pack + a gifted well charge. Clump → boom
   → cloud-inhale. The combo beat.
5. **The burn line** (first planet visit): a tumbling derelict falling in; you may save it
   (51's rescue) or watch it burn. Either way the player learns the atmosphere rule by
   *seeing* it once.

## Rules

- Each beat teaches *one* verb and is skippable on replays (veteran toggle at new-game).
- Teaching is diegetic: objectives + world setup, never modal tutorials (I-4).
- After onboarding, the codex (53) bestiary/verbs pages carry the reference role.

## Acceptance

- Fresh-save route: each beat fires once, in order, and its metric (did the player perform
  the verb) logs true.

# Pip and Spanner: intent and iterations

The two pit crew bodies make the existing Crucible fitting/repair screen feel inhabited while preserving the real wallet and fitting owners. Pip points at the actual selected item; Spanner only closes its jaws for an authoritative accepted purchase or repair receipt. Denials remain visible, repeated clicks cannot buy a different auto-selected item, and old-run/old-wave receipts cannot celebrate a new purchase. No new combat UI toasts, inventory owner, world actor or physics body were added.

The first visual study made Spanner's rails look soft and quilted. Firmer rear sections, long rigid rails, hinge caps and a consistent teal/cream Forge finish replaced that shape before current source screenshots were captured. Geometry is still a maker candidate for the local-primary art reviewer. The actual final source count is16,920 triangles;17,780 belonged to the earlier shape study. The two lower source alternatives are editable alternatives, not simultaneously selected runtime LODs.

The interaction reviewer found and the maker repaired stale hull-image callbacks, stale same-price and prior-wave receipts, auto-selected double purchases, synthesis/reentrant fitting rollback, replaced repair targets and campaign-state leakage. Existing runSession and survivalDraft remain authoritative. Receipt choreography is UI-clock driven and does not advance the paused simulation.

The lifetime check then found premature resource disposal after a logical decode timeout. The separately integrated decoder correction retains actual work and protects renderer successors; tests and limits are documented in the program's DECODER_RETIREMENT_HANDOFF.md.

Root's first canonical release build failed because the source recipe stamped asset and scene metadata but omitted the actual root. The corrected recipe stamps all three and truthfully declares one selectable tier. Exact original bytes and failure are under history/root-contract-v1; the independent parity review confirms all binary geometry/image data and every non-contract JSON value remain unchanged.

The next root check caught a second integration gap: direct compressed GLB decode passed, but the production public lease refuses unregistered release sources. Root used the existing generator and selected package builder to append Pip while preserving all295 previous pilots and runtime bindings. The maker is qualifying the actual public package load, rather than adding a development bypass.

Source renders are Blender previews. Composed screen raster, browser worker behavior, target GPU frame cost and final artistic acceptance remain open. The local-primary reviewer owns completion.

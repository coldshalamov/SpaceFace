## 2. Ranked findings

### F1 — `entity:destroyed` unbind still pays five whole-registry passes per corpse, inside the emit handling

- **evidence**: `src/render/renderer.js:15579-15620` — the `entity:destroyed` listener calls `this._unbindPresentationMesh(id, m)` at `:15613` per event (and at `:15592` on the recook-keep-gpu leg) with no batch open; `_unbindPresentationMesh` then runs the per-entity release `:20121-20125` plus the immediate identity release `globalXxxMotion.releaseMesh(mesh)` ×5 at `:20129-20138` (batch depth is 0 on this path). Each `releaseMesh` walks its whole record map — `shipMicroMotion.js:2284-2289` iterates `craftMotion.values()`, the other four registries same — so one corpse costs ~5×O(records) ancestor/membership scans inside the sim step that emitted the burst.
- **mechanism**: W83's `_meshReleasePending` batching covers the mass-evict sweeps, but the storm path is `entity:destroyed` itself — a kill burst fires N events, each paying the five registry passes inline on the same task that also runs `scene.remove`, `_noteShadowMeshRemoved`, and the corpse queue push (`:15614-15618`). N corpses → N×5 registry walks in one presented/sim frame, the exact fan-out the batching was built to collapse.
- **fix sketch**: defer only the *identity* release (the straggler class — `:20129-20138`) when no batch is open: push the mesh into a pending set and flush once per frame from `serviceRenderMeshResidency` (beside `drainDespawnDisposeQueue`, `:1989`) or on the next batch end. The per-entity-keyed release at `:20121-20125` stays immediate — keyed record readers (`getRecord(entity.id)`) resolve by current entity id and are already unreachable for straggler keys, so the deferral is semantics-identical to the W83 batch window. Keep `rebuildShipMesh` (`:21591`) and the boundary-helper sites (`:10055`, `:10069`) on the immediate path — they're rare single calls.
- **effort**: S–M.
- **magic-frame impact**: M — kill bursts are a named long-frame class (scoreboard C ~3 long tasks / E 538 excess ms); this is the one remaining unbatched mass-release path.
- **risk**: low — a dead tree's straggler refs stay pinned ≤1 frame; no keyed reader can observe them (verified under lane (a)).

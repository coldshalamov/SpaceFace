## Ranked findings

### F1 — Post-opening unstaged collects query the caller-minted `depthLightSig` while the paired depth drive signs marks with the epoch-checked `freshDepthLightSig()` — a mid-pass census drift makes the collect read a different signature than the marks it queries, over- or under-collecting the cohort

- **Evidence.** `src/render/renderer.js:15141-15147`: `depthLightSig = lightCensusSignature(scene)` and `depthLightSigEpoch = shadowCensusEpoch()` mint at pass entry; `freshDepthLightSig()` re-signs only when the epoch moved. `driveDepthCompile` evaluates `lightSigOverride: freshDepthLightSig()` per invocation (`:15163`) — the compile side is epoch-checked. The two unstaged collects are not: `collectUnstagedShadowCasters(renderer, depthSubjects.slice(i, i+512), scene, depthLightSig)` at `:15179` and the rescan-leg twin at `:15253` both pass the raw `depthLightSig`, and the collect resolves `lightSig = lightSigOverride` (`shadowDepthAdmission.js:485`) — every signature in `signatures.some(sig => !staged.has(sig))` (`:488-490`) is minted under the stale term. The collect legs yield per 512 subjects (`:15181`, `:15255`) across a `postPace()` — the pass spans presented frames, so `noteShadowCensusLightMutation` (e.g. `disposeObject`'s heldLight bump at `:25927`) can interleave.
- **Mechanism.** Two directions, both bounded: (1) census drift *after* the mint but *before* a collect — casters marked under `sig_old` (earlier stages, or a prior session) still satisfy the `sig_old` query → under-collect → the leg skips a re-stage the pass was chartered to fold in → the presented-frame flag collect (`collectUnstagedShadowCastersFlag` at `:10357`/`:24062`, which mints `this._shadowCensusForFrame()` fresh) reads `mark.l === sig_old` stale → withhold + arm re-stages under the live census. Net cost: a spurious withhold cycle per caster (castShadow off — the mesh still draws, only its shadow is absent) plus the deferred arm ceremony. (2) drift *after* a stage marked casters under `sig_new` — a later collect under `sig_old` re-mints signatures that miss every `staged` entry → over-collect → the drive re-stages and re-marks under `freshDepthLightSig()` = `sig_new` again — a redundant ceremony, self-correcting, bounded by the subject count. No cold-link path: marks and the staged-set entries are minted under the identical `lightSig` inside `markCastersDepthStaged` (`shadowDepthAdmission.js:516-517`), so a mark can never certify a sig its own staged keys don't satisfy; and the withheld-caster net (`castShadow=false` until the arm re-stages, `:10370`, `:24081-24109`) guarantees an unstaged-under-live-sig caster never reaches the shadow map in a presented frame. The residual is churn, not bricks — but it is churn the epoch check was added to eliminate, on exactly the pass it was added to.
- **Fix sketch.** Pass `freshDepthLightSig()` in place of `depthLightSig` at `:15179` and `:15253` (evaluate per slice iteration or per leg — per leg is enough: each slice yield is a macrotask, not a census boundary). Effort S.
- **Effort** S · **Magic-frame impact** L–M — no cold link traced; worst case is a one-cycle withhold churn on the post-drift cohort (shadows missing ~an arm cycle) plus one redundant staging ceremony; requires a light-census mutation inside the post-opening window · **Risk** low — the override already exists; the collect tolerates a mid-leg sig swap as over-collect (safe direction).

### F2 — `markLightSig` mints `''` when `lightingScene` is null while `lightCensusSignature(null)` returns `'l0|f0'` — latent divergence between the mark term and the collect term

- **Evidence.** `shadowDepthAdmission.js:604-611`: `markLightSig` resolves to `lightingScene ? (traverse ? fog|sorted : 'l0|f0') : ''`; `lightCensusSignature` at `:369-370` returns `'l0|f0'` for a null/non-traversable scene. `collectUnstagedShadowCasters` mints `lightCensusSignature(lightingScene)` when no override is passed (`:485`); `markCastersDepthStaged` mints `markLightSig` under the same fallback (`:502`). With `lightingScene: null` and no override, marks carry `l:''` while the collect queries `…|l0|f0` — `casterDepthMarkCurrent` fails on `mark.l !== lightSig` (`:309`) and every `staged` entry misses → casters read permanently unstaged → infinite withhold/re-stage churn (never a cold link; the withhold net holds).
- **Mechanism.** Latent only: every live call site passes a real `scene` (the four post-opening drives, the survival sweep at `:13160`, context restore `:9267`, session fallback `:24427`, warm `:11297`, pool seal `:12793`, cook pool `:14232`). The divergence is unreachable today but sits one `lightingScene: null` option away from a churn bug that looks like a stage that never lands.
- **Fix sketch.** Collapse the branches: `markLightSig = lightingScene && traverse ? `${fog}|${sorted}` : lightCensusSignature(lightingScene)` — or simply `'l0|f0'` in the null arm to match the census reader. Effort trivial.
- **Effort** S (one token) · **Magic-frame impact** L — unreachable today; if ever armed it produces churn, not a visual defect · **Risk** none.

## Lane hunts (a)–(e)

**(a) Mark-under-old-sig direction — bounded, both ways; the residual is the collect-side sig, not the marks.** Inside `markCastersDepthStaged` (`:495-519`) `staged.add(signature)` and `writeDepthMark(caster, lightSig)` mint from the same `lightSig` in the same call — a mark always certifies the sig its staged entries carry; no intra-call divergence exists. Across time: an epoch bump between the caller's mint (`:15141`) and a drive invocation is handled by `freshDepthLightSig()` (`:15146`, consumed `:15163`) — the stage signs with the live census. The unhandled direction is the *query* side (`:15179`, `:15253` pass stale `depthLightSig`) — traced fully in F1: under-collect defers to the withhold+arm net (bounded churn, never a cold link); over-collect pays one redundant ceremony. Mid-ceremony drift is also bounded: `lightSigOverride` is evaluated once per `driveDepthCompile` call before the iterator starts; a drift inside the stepped census yields links under the render-time light set but marks the at-call sig → the flag collect withholds and the arm re-stages — one withhold cycle per affected caster. **Wasted-restage bound: at most one redundant ceremony per drift event per cohort; severity L–M.**

**(b) Teardown leg skips — nothing uncleared.** The `.then` block holds no flags/latches: every leg is idempotent reskin (`upgradeBareRockMaterials` no-ops on dead or reskinned roots), compile (`compileObjectPipelines` try-wrapped), census (`warmAsteroidInstanceVariants` try-wrapped at `:9463-9466`), or depth stage (its own `stillLive` gate at `:9515`). Pre-W83 the identical work ran atomic in one microtask behind the same live-scene entry guard — no leg used to clear state the new skips leave set. **Clean.**

**(c) `markCastersDepthStaged` coverage — exactly two call sites, both drawn-gated.** `:738` (ceremony end — passes the pass's own `drawnDepthObjects` set + camera + `markLightSig`) and `:930` (staging-session `slice()` — passes `currentSliceDrawn` + camera + session `lightSig`). The `drawnDepthObjects && !drawnDepthObjects.has(caster)` guard (`:511-515`) skips undrawn casters except the layer-miss class (`!caster.layers.test(camera.layers)`), which marks under its mask term so a layer flip re-keys the signature. No path marks a caster that never drew nor one a release removed before the mark leg. **Clean.**

**(d) Nested batch-scope interleave — safe by construction.** `_meshReleasePending` is a single shared set and `_meshReleaseBatchDepth` a counter (`:20067-20083`): a nested scope's early return decrements to 1 and its finally runs `_meshReleaseBatchEnd`, but flush happens only at depth 0 → the inner scope's adds are held inside the shared pending set and flush with the outer scope's — one union flush, never a stranded inner set. No exit path skips the finally (all seven scopes enumerated above; abandons go through `iterator.return()`). **Clean.**

**(e) Reskin paths bypassing the `reskinnedLive` compile — none found that carry bare tags.** `spacefaceBareRock` tags mint only in `astMaterial` (`visualFactory.js:2319-2396`, common rock + untinted + library-not-ready).

# Serena Metadata Scope

`.serena/` is tool metadata, not SpaceFace product, architecture, design, ownership, or completion
authority. Cached symbols and ignored `memories/` may be stale session hints. Never use them to choose
an implementation, declare a file off-limits, stop at report-only work, or override the current task.

For live direction use, in order:

1. the applicable root and nested `AGENTS.md` files;
2. `ARCHITECTURE.md` for technical contracts;
3. the plan/spec explicitly activated by the task;
4. `design/program/README.md` for whole-program status;
5. current Git state, runtime maps, checks, and player-facing evidence.

If a Serena memory conflicts with those surfaces, ignore the memory. Do not edit or commit cache files.

### F1 — Deferred depth-stage legs re-pay the full staging ceremony per drive (was: session.slice amortization)
- **Evidence:** `src/render/shadowDepthAdmission.js:534-790` (traverse :583-614, fresh Scene + `admissionKeyLight` clone :637-641, reparent :653-659/:730-733, census render :745-748 + real render :758, restore :777-789); unconditional arm call `src/render/renderer.js:25043-25054`; 7 drive sites (:9468/:9725/:11541/:13061/:13429/:14510/:15445); `createShadowDepthStagingSession` dead at :818; `driveCompileShadowDepthPipelines` stale-retry up to 4 attempts (`renderer.js:526-547`).
- **Mechanism:** staging (scene clone + light reparent + 2 renders + whole-scene traverse) is minted fresh per drive and discarded in `finally`; legs with tiny subject lists are dominated by fixed cost, and under stale retries the ceremony multiplies — the old session path amortized across legs keyed on lightSig. Off-frame paced, so the cost lands as longer withheld-caster windows (shadow pop-in delay) and extra staged renders competing inside shell/pump budgets, not presented-frame hitching.
- **Fix sketch:** restore lightSig-keyed staging reuse — cache `{stagingScene, keyLight clone, stagedLights reparent state}` across drives, invalidated on `lightSigEpoch` change / stagedLights set change (epoch guard same shape as `_reconcileEpoch`); the census+markCasters legs still run per drive so correctness is untouched. Alternatively add a fast-path when `deferredMark` is empty and no staged lights moved, and either delete or wire `createShadowDepthStagingSession` (currently dead) — small-subject legs then skip the render pair entirely.
- **Effort:** M. **Magic-frame impact:** M (faster queue drain + casters unblock sooner → fewer visible late shadows; no presented-frame cost today). **Risk:** M (staging reuse must respect light churn and the keepGpu/abandon machinery — exactly the hazard class the unconditional drive was presumably minted to kill).

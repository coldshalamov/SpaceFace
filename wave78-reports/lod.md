## Ranked findings

### F1 — Over-cover-queued roots are never withheld: `band===1 && selfDirty && queued && !cached` falls through `_syncShadowCasterPolicyChecked`'s else-if chain into a live `allowCast` restore — unstaged casters draw in the presented shadow refresh

- **Evidence.** Two feeders queue a root with `invalidateShadowCasterPolicy` + `STAGE_SELF_DIRTY_KEY = dirtySeq` stamp but *no* withhold and *no* `_withheldDepthCasters` cache entry: `_stageShadowDepthOnSettingEnable`'s `queueOverCover` loop (`renderer.js:22686-22696`) — the comment at `:22669` states the intent "queued roots withhold at their next sync" — and `admitFlightShadowDepth`'s over-cover leg (`renderer.js:9817-9836`, skips the withhold at `:9817` then still invalidates/stamps/queues at `:9833-9836`). At the next `_syncShadowCasterPolicyChecked` (`:22020-22190`) on such a root: `collectGate` is dead because the band-1 clause requires `dirtySeq > stampedSeq` (`:22079`) and the feeder just stamped `stampedSeq === dirtySeq`; then the else-if chain has no matching branch — `band !== 1 && queued` (`:22132`) fails on band, `band === 1 && selfDirty && queued && this._withheldDepthCasters` (`:22134`) reaches the cached check at `:22135-22147` but `.get(root)` misses (nothing was ever withheld on it) → control falls through to `syncShadowCasterPolicy(root, lodLevel, { ...opts, out })` at `:22149-22151` with live `opts.allowCast === true` — a dirty traverse that writes `castShadow = allowCast && opaqueReceiver` on every eligible mesh (`shadowCasterPolicy.js:283-310`). Contrast the *checked-sync's own* over-cover branch at `:22126-22131`, which does withhold whole-subtree (`syncOpts = {...opts, allowCast:false}`, stamping `castBand=0` so later syncs take `band!==1 && queued`).
- **Mechanism.** `_syncShadowMapEnabled` flips `_keyLight.castShadow` on every toggle (`:22772-22804`) and `lightCensusSignature` bakes each light's `castShadow` flag into the census (`shadowDepthAdmission.js:341`), so OFF→ON **always** re-mints the census — every `sfDepthMark` goes stale, every castable mesh is genuinely unstaged, and `toggleBudget` (`SHADOW_DEPTH_PASS_NODE_CAP = 4096`, shared across all top-level `scene.children`, debited per *visited* node incl. non-drawables at `shadowDepthAdmission.js:186`) dies inside the first fat root on any busy sector. `queueOverCover` then holds the abort root plus **every unvisited sibling** (`:22671-22675`). Roots that get synced (entity boundary policy roots) hit the fallthrough above; wrapper roots that never get a policy sync are simply never withheld at all — same end state. Either way the unstaged casters keep `castShadow=true` and draw in the first presented shadow refresh, which is where three.js lazily links their depth-variant programs — a cold program-link burst inside the presented frame, the exact failure class the toggle stage exists to prevent, landing on the fattest roots (the ones most likely to hold many distinct material variants). Ordering is deterministic, not a race: the sync runs inside the presented frame's `syncEntityViews`; the arm fires post-present via `armCallbackAfterPresent` (`compilePresentSlice.js:258-273`). Feeder B reachability is narrower — needs `castBand===1`, i.e. a root that synced `allowCast=true` before the over-cover queue (a flight-admission batch whose shared 4096-node `flagBudget` is drained by an early fat root leaves all later roots over-cover).
- **Fix sketch.** Withhold at queue time, mirroring the checked sync's own over-cover branch: in both feeders run `syncShadowCasterPolicy(root, lod, { allowCast:false, out:... })` (stamps `castBand=0`, whole subtree withheld, subsequent syncs take `band!==1 && queued` → stays withheld until the arm re-derives + restores). This covers never-synced wrapper children too. A narrower sync-side alternative: map `band === 1 && selfDirty && queued && !cached` to `syncOpts = { ...opts, allowCast:false }` — same end state for synced roots but leaves never-synced wrappers live.
- **Effort** S · **Magic-frame impact** H (deterministic per OFF→ON on scenes exceeding 4096 caster-walk nodes; a burst of cold depth-variant links inside the presented refresh) · **Risk** L — over-withhold is the designed safe state; the arm restores under live policy and the leg/leftover machinery is unchanged.

### F2 — `depthNodeScale` is dropped on park: a permanently over-cap root re-pays the 1→2→4→8 escalation ladder (~4 aborting collect walks) on every unpark cycle

- **Evidence.** Escalation lives on the pending entry: `entry.depthNodeScale = Math.min(8, (entry.depthNodeScale || 1) * 2)` (`renderer.js:22374`) and survives re-queue via the spread at `:22217`. But both park records store only `{lodLevel, entity, seq, recheck, lightSig, oqX, oqZ}` — no `depthNodeScale` (`:22363-22371` abortedPark, `:22518-22529` leftover park). Unpark paths (`parkedRelease` `:22041-22045`; parked-empty `:22119-22125`) re-enter through the normal collect → withhold → `_queueShadowDepthStage`, which mints a fresh `{}` entry → scale resets to 1.
- **Mechanism.** A root that still over-covers at scale 8 (>32768 visited nodes under its subtree) re-pays four bounded collect walks (4096→32768) across four arms before re-parking — once per dirtySeq/lightSig/ortho-cell drift or backed-off recheck. Each arm's collect runs post-present inside the ledger budget, so the cost is real but capped (~4 bounded walks per cycle).
- **Fix sketch.** Carry `depthNodeScale` in the parked entry (same place `lodLevel`/`entity`/`seq` already ride) and restore it into the re-queued pending entry; a permanently-fat root then goes straight to re-park on its next offer.
- **Effort** S · **Magic-frame impact** L (bounded re-burn per unpark cycle, needs a >32k-node root to matter) · **Risk** L.

## Lane hunts — verdicts

**(a) `entry.depthNodeScale` writers/readers.** Writers: `:22374` (escalate ×2, cap 8) only. Readers: `:22343` (per-root `collectNodeBudget`) and `:22348` (park-at-8 test). It never decays within a queue life — a root that once over-covered keeps its wallet until the entry dies (completion, or park which drops the field → F2). The queue-order hazard in the prompt — `slice[0]`'s scale sizing the whole arm's shared budget — is **fixed**: W76 per-root budgets (`:22342-22344` — `collectNodeBudget` is minted per entry, not shared). A first-queued over-covered root cannot inflate siblings' slices.

**(b) caller-match gate** (`_unbindPresentationMesh`, `renderer.js:18588-18653`). `callerMatches = !marked || entityId == null || mark === entityId` (`:18594-18596`); release pays `releaseId = marked ? mark : entityId` (`:18602`); marks cleared only under `callerMatches` (`:18609-18612`); `world.unbindMesh` is mesh-identity guarded (`presentationWorld.js:733-737`). All 14 src call sites (`:1761, :7306, :7349, :7854, :9514, :9528, :11500, :13575, :14244, :14265, :18796, :18973, :19106, :19689`) pass a non-null entity id — every caller means "unbind if mine"; the `entityId == null` arm is defensive-only, and releasing under the mark's owner is correct there (claims were keyed under the mark at note time — pre-W76's release-under-null could not reach that set → leak). A mismatched caller skips release + preserves the mark; the world unbind then either no-ops (identity guard) or drops only the caller's own slot. Sound.

**(c) `UNSTAGED_COLLECT_OVER_COVER` sites** — every call site enumerated: checked sync `collectUnstagedShadowCastersFlag` `:22096` (sentinel → `overCovered` → whole-subtree withhold + queue, correct); arm `collectUnstagedShadowCasters` `:22345` (sentinel → escalate or park at scale 8, correct); toggle flag `:22664` (sentinel → `queueOverCover` — withhold skipped → F1); flight flag `:9816` (sentinel → skip withhold, still queue → F1); post-opening signature collects `:13840`/`:13925` pass **no** `nodeBudget` → `_walkBudgetAbort` unreachable → sentinel cannot be produced → `.length` reads are safe. No site treats the sentinel as a legit list; the two correct handlers still skip the withhold — that is F1, not a sentinel bug. (Note: the sentinel is a plain string `'sfUnstagedCollectOverCover'` — a *missing* sentinel check would fail open via truthy `.length`; all current sites compare `===` first.)

**(d) Arm per-root budget + atomicity.** Per-root since W76 (`:22342-22344`); on abort the root's `found` never touches `unstagedByRoot`/`unstaged` (`:22347-22377` break) — the withheld set stays withheld and cannot partially stage through that path (the leg cap can legitimately split a *collected* set, tracked via `leftoverByRoot` re-proof `:22458-22467` + requeue `:22535`). The pending-Map requeue preserves `{lodLevel, entity}` exactly — same entry object re-set at `:22389`/`:22535`/`:22598`, and `_queueShadowDepthStage` merges `...(pending.get(root) || {})` so escalation fields survive (`:22217`).

**Whole-ship LOD family** (`partsLibrary.js:8779-9060`): runtime demotion is off (`wholeShipLodPolicy.js:18` `WHOLE_SHIP_LOD_RUNTIME_DEMOTION = false` — owner ruling: a live ship keeps the body its admission built); `resolveLiveWholeShipLodTransition` maps `load`→`keep`; `selectPrewarmLodLevel` pins `lod0`; resident-level `swapTo` is atomic (remove prev + add next in one task, no blank frame); demoted roots compile/upload hidden before swap (`prepareAuthoredShipVisualPipelines` `:9032`); `roots.lod0`/`adopt` seeding prevents hysteresis thrash.

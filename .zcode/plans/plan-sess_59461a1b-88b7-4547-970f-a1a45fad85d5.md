A new **inline analysis panel** that appears when a row is clicked (replacing the modal-only flow; the modal stays for fullscreen but clicking a row now populates a persistent stage in the center column). Panel mounts the real effect factories ONCE in a try/catch (mirroring stationHub's pattern):

### Step 3 — Trade inspector
A panel section showing: cargo-aware quote (call `econ.quote(stationId,cmdtyId,side,qty)` → unitAvg/total/priceImpact/stockAfter), **flooding impact as a circularGauge** (the real `createCircularGauge` showing how a large sell would crater local price — derived from priceImpactPct), **projected profit as a morphLabel ticker** (numeric:true, morphs only after a transaction — reads `state.player.tradeLots` cost basis), and a "Plot Route" action that calls `applyTradeNavigation`.

### Step 4 — Event mode
On `economy:eventStarted`/`economy:eventEnded` (already wired to refresh market), emit a **rippleField ping** on the analysis stage + set the **routeBeam** active for shortage/boom/blockade/piracy events affecting the selected commodity. The news ticker already routes through voiceArbiter (`marketNews.js` `helpers.voice.say('news')`) — verify that path is intact; no new one-voice wiring needed.

### Step 5 — CSS (in stationHub.js `STATION_CSS`)
Append the market-scope styling: scope-readout rows, gauge integration, the analysis stage grid, cone shading — all palette tokens only, 3 sizes per surface, no pulses at rest.
